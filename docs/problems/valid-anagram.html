有效的字母异位词

简单 LeetCode 原题 ↗
主模板计数统计→

题目

给定两个字符串 s 和 t，编写一个函数来判断 t 是否是 s 的字母异位词，即两个字符串包含的字母及各字母数量完全相同（仅顺序可能不同）。进阶：如果输入字符串包含 Unicode 字符该怎么办？

示例 1
输入s = "anagram", t = "nagaram"
输出true
示例 2
输入s = "rat", t = "car"
输出false

思路

判断是否互为异位词，是计数统计的信号：26 位计数数组对 s 累加、对 t 扣减，全部扣减后不出现负数即为异位词。变化点在长度不等可提前返回，以及扣减中一旦出现负数立即判负。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def isAnagram(self, s, t):3        if len(s) != len(t):                    # 变化点: 长度不等直接剪枝4            return False5        cnt = [0] * 266        for ch in s:7            cnt[ord(ch) - ord('a')] += 18        for ch in t:9            idx = ord(ch) - ord('a')10            cnt[idx] -= 111            if cnt[idx] < 0:                    # 变化点: 任何字母透支即不是异位词12                return False13        return True

变化点代码

  • L3

    长度不等直接剪枝

  • L11

    任何字母透支即不是异位词

易错点

  • 01

    长度不等的字符串不可能是异位词，先比长度可省一次遍历

  • 02

    26 位数组只适用小写字母；含 Unicode 时改用字典计数（Counter）

  • 03

    只比较计数集合（各字母是否出现）不够，数量也要一致

复杂度

时间复杂度O(n)
空间复杂度O(1)（26 位计数数组）
