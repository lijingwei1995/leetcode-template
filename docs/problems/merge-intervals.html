合并区间

中等 LeetCode 原题 ↗
主模板区间贪心→

题目

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [start_i, end_i]。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

示例 1
输入intervals = [[1,3],[2,6],[8,10],[15,18]]
输出[[1,6],[8,10],[15,18]]
示例 2
输入intervals = [[1,4],[4,5]]
输出[[1,5]]

思路

合并重叠区间是区间贪心的信号：先按左端点排序，再线性扫描，当前起点不超过上一结果的右端就合并。变化点在合并时右端取 max——被合并区间的右端可能比当前结果更长，不能直接覆盖。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def merge(self, intervals):3        intervals.sort(key=lambda x: x[0])      # 变化点: 按左端点排序4        res = []5        for start, end in intervals:6            if res and start <= res[-1][1]:7                res[-1][1] = max(res[-1][1], end)   # 变化点: 重叠则扩张右端，取 max8            else:9                res.append([start, end])10        return res

变化点代码

  • L3

    按左端点排序

  • L7

    重叠则扩张右端，取 max

易错点

  • 01

    排序后只需比较当前起点与上一区间的右端，无需两两比较

  • 02

    相接也算重叠：[1,4] 与 [4,5] 的 4 相等要合并，判定用 <= 而非 <

  • 03

    合并右端必须取 max，直接赋 end 会丢掉更长的右边界

复杂度

时间复杂度O(n log n)
空间复杂度O(n)
