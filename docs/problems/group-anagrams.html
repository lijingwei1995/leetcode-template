字母异位词分组

中等 LeetCode 原题 ↗
主模板哈希映射→

题目

给你一个字符串数组 strs，请你将字母异位词组合在一起。字母异位词是由重新排列源单词的所有字母得到的新单词，返回结果列表可以按任意顺序排列。

示例 1
输入strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出[["bat"],["nat","tan"],["ate","eat","tea"]]
示例 2
输入strs = [""]
输出[[""]]]

思路

把互为异位词的单词收进同一组，是哈希映射分组的信号：为每个单词求一个规范形作 key，value 是该组的单词列表。变化点在 key 的选取——排序后的字符串（也可用 26 位计数的元组），setdefault 一次完成收集。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def groupAnagrams(self, strs):3        groups = {}4        for s in strs:5            key = "".join(sorted(s))            # 变化点: 排序后的字符串作分组键6            groups.setdefault(key, []).append(s)    # 变化点: 键不存在则建组，存在则追加7        return list(groups.values())

变化点代码

  • L5

    排序后的字符串作分组键

  • L6

    键不存在则建组，存在则追加

易错点

  • 01

    不能用原字符串当 key，否则同组异位词会被拆开

  • 02

    除排序字符串外，也可把 26 位计数转成元组当 key，避免排序开销

  • 03

    返回值只需同组元素聚在一起，组与组的顺序、组内顺序都不限

复杂度

时间复杂度O(n·k log k)（k 为单词平均长度）
空间复杂度O(n·k)
