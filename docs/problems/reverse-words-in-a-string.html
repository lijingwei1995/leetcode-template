反转字符串中的单词

中等 LeetCode 原题 ↗
主模板字符串扫描与模拟→

题目

给你一个字符串 s，请你反转字符串中单词的顺序。单词是由非空格字符组成的字符串，s 中可能存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词之间应当仅用单个空格分隔，且不包含任何额外的空格。

示例 1
输入s = "the sky is blue"
输出"blue is sky the"
示例 2
输入s = " hello world "
输出"world hello"

思路

单词顺序反转且要清理多余空格，字符串扫描信号：从右往左扫，跳过空格、截取单词、按遇到顺序拼接。反向截到的单词天然就是目标顺序。变化点在于扫描方向是反向，以及拼接用 ' '.join 保证单词间恰好一个空格。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def reverseWords(self, s):3        words = []4        i = len(s) - 15        while i >= 0:6            while i >= 0 and s[i] == ' ':       # 变化点: 反向扫描跳过多余空格7                i -= 18            if i < 0:9                break10            end = i11            while i >= 0 and s[i] != ' ':12                i -= 113            words.append(s[i + 1:end + 1])      # 变化点: 反向截取的单词天然符合新顺序14        return ' '.join(words)

变化点代码

  • L6

    反向扫描跳过多余空格

  • L13

    反向截取的单词天然符合新顺序

易错点

  • 01

    单词间可能连续多个空格，两段内层循环都不能漏 i >= 0 判断

  • 02

    拼接用 ' '.join(words)，手动加空格容易产生尾随空格

  • 03

    s[i+1:end+1] 的左端点是 i+1（i 停在空格或 -1 上），下标错一格就截错词

复杂度

时间复杂度O(n)
空间复杂度O(n)
