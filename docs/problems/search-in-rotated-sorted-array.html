搜索旋转排序数组

中等 LeetCode 原题 ↗
主模板二分边界与旋转数组→

题目

整数数组 nums 原本按升序排列且元素互不相同，在未知下标处发生了旋转（如 [0,1,2,4,5,6,7] 旋转后变为 [4,5,6,7,0,1,2]）。给定 target，若它在数组中返回其下标，否则返回 -1。要求时间复杂度为 O(log n)。

示例 1
输入nums = [4,5,6,7,0,1,2], target = 0
输出4
示例 2
输入nums = [4,5,6,7,0,1,2], target = 3
输出-1

思路

旋转数组每轮至少有一半是有序的，这是边界二分的信号：先判断哪一半有序，再看 target 是否落在该有序区间内。nums[left] <= nums[mid] 说明左半有序；若 nums[left] <= target < nums[mid] 则留在左半，否则去右半。变化点在于“判有序侧 + 判区间”两层条件的嵌套。

识别信号→ 套用模板→ 调整变化点

模板解法

1class Solution:2    def search(self, nums, target):3        left, right = 0, len(nums) - 14        while left <= right:5            mid = (left + right) // 26            if nums[mid] == target:7                return mid8            if nums[left] <= nums[mid]:         # 变化点: 判断左半是否有序9                if nums[left] <= target < nums[mid]:10                    right = mid - 111                else:12                    left = mid + 113            else:                               # 变化点: 右半有序，按区间决定方向14                if nums[mid] < target <= nums[right]:15                    left = mid + 116                else:17                    right = mid - 118        return -1

  • L13

易错点

  • 01

    判断左半有序要用 <=：区间剩两个元素时 left == mid，缺等号会走错分支

  • 02

    target 落在有序半的判断必须带区间端点：nums[left] <= target < nums[mid]

  • 03

    本题元素互异；若允许重复（81 题变体）需要额外的退化处理
