删除排序链表中的重复元素 II

中等 LeetCode 原题 ↗
主模板链表哨兵与遍历→

题目

给定一个已排序的链表的头 head，删除原始链表中所有重复数字的节点，只留下不同的数字。返回已排序的链表。注意：出现次数超过一次的数字要全部删除，一个都不保留。

示例 1
输入head = [1,2,3,3,4,4,5]
输出[1,2,5]
示例 2
输入head = [1,1,1,2,3]
输出[2,3]

思路

把重复值整段删光（一个不留）是链表哨兵的信号：prev 停在“确定保留”的段尾，发现相邻两值相等就记下该值，把后续所有等值节点全部摘除。变化点在内层 while 按值跳过、且删除期间 prev 不动。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def deleteDuplicates(self, head):3        dummy = ListNode(0, head)4        prev = dummy5        while prev.next and prev.next.next:6            if prev.next.val == prev.next.next.val:     # 变化点: 发现重复值7                dup = prev.next.val8                while prev.next and prev.next.val == dup:   # 变化点: 内层循环摘除该值全部节点9                    prev.next = prev.next.next10            else:11                prev = prev.next12        return dummy.next

变化点代码

  • L6

    发现重复值

  • L8

    内层循环摘除该值全部节点

易错点

  • 01

    发现重复要先把 dup 值记下来，再整体跳过所有等值节点，不能用逐个比较

  • 02

    删除期间 prev 不动：下一个节点可能还是新值，等确认唯一再前移

  • 03

    头节点就重复时靠 dummy 兜底，返回 dummy.next

复杂度

时间复杂度O(n)
空间复杂度O(1)
