最长公共前缀

简单 LeetCode 原题 ↗

题目

编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 ""。所有输入只包含小写英文字母。

示例 1
输入strs = ["flower","flow","flight"]
输出"fl"
示例 2
输入strs = ["dog","racecar","car"]
输出""

思路

公共前缀要同时约束所有字符串，字符串扫描信号：以第一个串为基准做纵向逐列比较。任一列在某串上越界或字符失配，当前列下标就是公共前缀长度。变化点在于扫描维度是“列”而非“行”，且越界判断要在取 other[i] 之前完成。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def longestCommonPrefix(self, strs):3        for i in range(len(strs[0])):           # 变化点: 逐列纵向扫描4            ch = strs[0][i]5            for other in strs[1:]:6                if i == len(other) or other[i] != ch:   # 变化点: 先判越界再取字符7                    return strs[0][:i]8        return strs[0]

变化点代码

  • L3

    逐列纵向扫描

  • L6

    先判越界再取字符

易错点

  • 01

    判断“某串先结束”要在取 other[i] 之前，否则下标越界

  • 02

    strs[0] 可能为空串，外层循环不进入直接返回 ""，天然兼容

  • 03

    失配时返回 strs[0][:i]，不是从头拼一个新字符串

复杂度

时间复杂度O(m·n)（m 为串长，n 为串数）
空间复杂度O(1)
