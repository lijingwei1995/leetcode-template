分发糖果

困难 LeetCode 原题 ↗
主模板线性贪心→

题目

n 个孩子站成一排，每个孩子有一个整数评分 ratings。你需要按照以下要求给孩子们分发糖果：每个孩子至少分配到一个糖果；相邻两个孩子中评分更高的那个可以获得更多的糖果。返回你需要准备的最少糖果数目。

示例 1
输入ratings = [1,0,2]
输出5
示例 2
输入ratings = [1,2,2]
输出4

思路

相邻约束只涉及左右两个邻居，线性贪心信号：拆成两个单向约束分别处理——从左到右保证比左邻评分高就多一颗，再从右到左保证比右邻评分高就不少于右邻加一。变化点在于第二遍必须反向扫描，并用 max 合并两次结果使两个约束同时成立。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def candy(self, ratings):3        n = len(ratings)4        candies = [1] * n5        for i in range(1, n):                   # 变化点: 左到右处理“比左邻高”的约束6            if ratings[i] > ratings[i - 1]:7                candies[i] = candies[i - 1] + 18        for i in range(n - 2, -1, -1):          # 变化点: 右到左处理“比右邻高”，取 max 合并9            if ratings[i] > ratings[i + 1]:10                candies[i] = max(candies[i], candies[i + 1] + 1)11        return sum(candies)

变化点代码

  • L5

    左到右处理“比左邻高”的约束

  • L8

    右到左处理“比右邻高”，取 max 合并

易错点

  • 01

    评分相等不构成约束，不要给相等评分的孩子追加糖果

  • 02

    第二遍必须从右往左，方向反了右侧约束无法传递

  • 03

    合并两遍结果用 max，直接覆盖会破坏第一遍已满足的约束

复杂度

时间复杂度O(n)
空间复杂度O(n)
