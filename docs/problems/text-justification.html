文本左右对齐

困难 LeetCode 原题 ↗
主模板字符串扫描与模拟→

题目

给定一个单词数组 words 和一个宽度 maxWidth，重新排版文本，使每行恰好有 maxWidth 个字符且左右两端对齐。贪心策略：每行放置尽可能多的单词；单词间空格数尽量均匀分配，无法均匀时左侧空格多于右侧；最后一行应左对齐且单词间只放一个空格，行尾补空格。

示例 1
输入words = ["This", "is", "an", "example", "of", "text", "justification."], maxWidth = 16
输出["This is an", "example of text", "justification. "]
示例 2
输入words = ["What","must","be","acknowledgment","shall","be"], maxWidth = 16
输出["What must be", "acknowledgment ", "shall be "]

思路

排版规则是“贪心打包 + 空格分配”，字符串扫描信号：逐词装行，装不下就结算当前行。非末行把缺的空格均分到词间缝隙、余数落在左侧缝隙；末行与单单词行左对齐补空格。变化点在于装行判断要带上当前词数（即缝隙数），以及 divmod 后余数分配给左侧缝隙。

1class Solution:2    def fullJustify(self, words, maxWidth):3        result, line, width = [], [], 04        for w in words:5            if width + len(w) + len(line) > maxWidth:   # 变化点: 预判装不下再结算当前行6                result.append(self._justify(line, width, maxWidth))7                line, width = [], 08            line.append(w)9            width += len(w)10        last = ' '.join(line).ljust(maxWidth)           # 变化点: 末行左对齐、行尾补空格11        return result + [last]12 13    def _justify(self, line, width, maxWidth):14        gaps = len(line) - 115        if gaps == 0:16            return ''.join(line).ljust(maxWidth)17        base, extra = divmod(maxWidth - width, gaps)    # 变化点: 余数空格落到左侧缝隙18        parts = []19        for i, w in enumerate(line):20            parts.append(w)21            if i < gaps:22                parts.append(' ' * (base + (1 if i < extra else 0)))23        return ''.join(parts)

变化点代码

  • L5

    预判装不下再结算当前行

  • L10

    末行左对齐、行尾补空格

  • L17

    余数空格落到左侧缝隙

易错点

  • 01

    装行判断是 width + len(w) + len(line) > maxWidth，len(line) 是当前词数也是缝隙数，漏加会塞太满

  • 02

    末行与单单词行都要 ljust 补齐，不能走均匀分配分支

  • 03

    divmod 的余数必须分配给左侧缝隙，分给右侧会与标准输出不符

复杂度

时间复杂度O(N)（N 为全部字符总数）
空间复杂度O(N)
