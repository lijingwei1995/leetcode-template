题目

给定一个由整数组成的非空数组 digits，表示一个非负整数，最高位数字在数组开头。对该整数加一，并返回表示结果的数组。

示例 1
输入digits = [1,2,3]
输出[1,2,4]
示例 2
输入digits = [9]
输出[1,0]

思路

整数按位存于数组，加一只需从末位向前处理进位：小于 9 的位加一即结束，等于 9 的位置 0 继续进位，是数学模拟的典型形。变化点在于用“提前返回”代替显式进位变量，全部为 9 时在头部补 1 扩一位。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def plusOne(self, digits):3        for i in range(len(digits) - 1, -1, -1):    # 变化点: 从末位向前处理进位4            if digits[i] < 9:5                digits[i] += 16                return digits                   # 变化点: 无进位即结束7            digits[i] = 08        return [1] + digits                     # 变化点: 全 9 需扩一位

变化点代码

  • L3

    从末位向前处理进位

  • L6

    无进位即结束

  • L8

    全 9 需扩一位

易错点

  • 01

    最高位在下标 0，必须从末位开始向前扫描

  • 02

    遇小于 9 的位加一后立即返回，不要继续循环

  • 03

    全 9 时要新建数组并在头部补 1，不能原地扩容

复杂度

时间复杂度O(n)
空间复杂度O(1)（全 9 时 O(n) 新数组）
