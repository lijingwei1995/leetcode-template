N 皇后 II

困难 LeetCode 原题 ↗
主模板回溯框架→

题目

n 皇后问题研究如何将 n 个皇后放置在 n×n 的棋盘上，且任意两个皇后不能互相攻击——即不能处于同一行、同一列或同一条对角线（两个方向都算）。本题只需求出不同的解决方案的数量，不需要返回具体的棋盘布局。

示例 1
输入n = 4
输出2
示例 2
输入n = 1
输出1

思路

逐行放置天然消去行冲突，信号是回溯框架：列冲突用 cols 集合判重，两条斜线方向分别用行减列 r-c、行加列 r+c 两个不变量作键。变化点在于本题只要方案数——递归走到第 n 行时计数加一，无需维护 path 或棋盘，撤销时三个集合成对删除。

识别信号→ 套用模板→ 调整变化点

模板解法

1class Solution:2    def totalNQueens(self, n):3        cols, diag1, diag2 = set(), set(), set()4        count = 05 6        def backtrack(r):7            nonlocal count8            if r == n:                             # 变化点: 只数方案数，不保存棋盘9                count += 110                return11            for c in range(n):12                if c in cols or (r - c) in diag1 or (r + c) in diag2:   # 变化点: 列与两条对角线判重13                    continue14                cols.add(c)15                diag1.add(r - c)16                diag2.add(r + c)17                backtrack(r + 1)18                cols.remove(c)                     # 撤销选择19                diag1.remove(r - c)20                diag2.remove(r + c)21 22        backtrack(0)23        return count

变化点代码

  • L8

    只数方案数，不保存棋盘

  • L12

    列与两条对角线判重

易错点

  • 01

    对角线判重的键是 r-c 与 r+c，只判列会漏掉斜线攻击

  • 02

    撤销时三个集合成对 remove，漏任何一个都会污染后续分支

  • 03

    本题返回方案数，误建棋盘列表既费内存又容易偏离题意

复杂度

时间复杂度O(n!)
空间复杂度O(n)（递归栈与三个集合）
