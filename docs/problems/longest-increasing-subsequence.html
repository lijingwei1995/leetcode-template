最长递增子序列

中等 LeetCode 原题 ↗
主模板线性 DP→相关模板二分查找→

题目

给定整数数组 nums，找到其中最长严格递增子序列的长度。子序列由数组派生而来，删除（或不删除）元素而不改变其余元素顺序。

示例 1
输入nums = [10,9,2,5,3,7,101,18]
输出4
示例 2
输入nums = [7,7,7,7,7]
输出1

思路

“以第 i 个元素结尾的最长递增子序列”只依赖更小的下标，适合线性 DP。dp[i] 表示以 nums[i] 结尾的 LIS 长度，内层枚举 j < i 且 nums[j] < nums[i] 转移。变化点在于答案不是 dp[n-1]，而是所有 dp[i] 的最大值。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def lengthOfLIS(self, nums):3        if not nums:4            return 05        dp = [1] * len(nums)6        for i in range(len(nums)):7            for j in range(i):                       # 变化点: 只从更小的前驱转移8                if nums[j] < nums[i]:9                    dp[i] = max(dp[i], dp[j] + 1)10        return max(dp)

变化点代码

  • L7

    只从更小的前驱转移

易错点

  • 01

    要求严格递增，判断必须是 nums[j] < nums[i] 而不是 <=

  • 02

    答案是 max(dp)，不是 dp[-1]

  • 03

    可用贪心 + 二分把时间复杂度优化到 O(n log n)

复杂度

时间复杂度O(n²)
空间复杂度O(n)
