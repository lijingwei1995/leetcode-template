跳跃游戏 II

中等 LeetCode 原题 ↗
主模板线性贪心→

题目

给定一个长度为 n 的 0 索引整数数组 nums，初始位置为 nums[0]，每个元素代表在该位置可以跳跃的最大长度。你的目标是到达最后一个下标，返回到达它所需的最少跳跃次数。测试用例保证可以到达。

示例 1
输入nums = [2,3,1,1,4]
输出2
示例 2
输入nums = [2,3,0,1,4]
输出2

思路

最少跳跃次数可按“每一跳覆盖的区间”分层，线性贪心信号：扫描时维护本层边界 end 与可达最远 farthest，走到边界就必须再跳一步，并把边界更新为 farthest。变化点在于“到达边界即步数加一”的时机（先更新 farthest 再计数），以及扫描停在倒数第二个位置避免多计一步。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def jump(self, nums):3        steps, end, farthest = 0, 0, 04        for i in range(len(nums) - 1):          # 变化点: 停在倒数第二个位置，避免终点多计一步5            farthest = max(farthest, i + nums[i])6            if i == end:                        # 变化点: 走到本层边界，必须再跳一次7                steps += 18                end = farthest9        return steps

变化点代码

  • L4

    停在倒数第二个位置，避免终点多计一步

  • L6

    走到本层边界，必须再跳一次

易错点

  • 01

    先更新 farthest 再判断 i == end，顺序反了会把旧边界当成新边界

  • 02

    扫描只到 len(nums)-2，扫到终点会在最后一层多计一次跳跃

  • 03

    题目保证可达，无需处理“end == i 且 farthest 不再前进”的死局场景

复杂度

时间复杂度O(n)
空间复杂度O(1)
