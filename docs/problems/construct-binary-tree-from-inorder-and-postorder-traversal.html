从中序与后序遍历序列构造二叉树

中等 LeetCode 原题 ↗
主模板二叉树递归→相关模板分治→

题目

给定两个整数数组 inorder 和 postorder，其中 inorder 是二叉树的中序遍历，postorder 是同一棵树的后序遍历，构造二叉树并返回其根节点。假设树中没有重复的值。

示例 1
输入inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
输出[3,9,20,null,null,15,7]
示例 2
输入inorder = [-1], postorder = [-1]
输出[-1]

思路

后序末元素是根，与 105 题同属分治构造，仍是树递归模板，只是根来自数组尾部、指针递减。中序哈希定位切分点后递归构造左右子树。变化点：必须先递归建右子树再建左子树，因为指针从后往前消耗时，右子树的后序段恰好排在左子树之后。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def buildTree(self, inorder, postorder):3        idx = {v: i for i, v in enumerate(inorder)}4        self.pos = len(postorder) - 15 6        def build(left, right):7            if left > right:8                return None9            root = TreeNode(postorder[self.pos])10            self.pos -= 1                             # 变化点: 后序从尾部倒序取根11            mid = idx[root.val]12            root.right = build(mid + 1, right)        # 变化点: 必须先建右子树再建左子树13            root.left = build(left, mid - 1)14            return root15 16        return build(0, len(inorder) - 1)

变化点代码

  • L10

    后序从尾部倒序取根

  • L12

    必须先建右子树再建左子树

易错点

  • 01

    指针从 len(postorder)-1 起递减，根取的是 postorder 末尾元素

  • 02

    先建右子树、后建左子树，顺序写反会把右子树的根错配给左子树

  • 03

    空数组时 build(0, -1) 直接返回 None，无需单独特判

复杂度

时间复杂度O(n)
空间复杂度O(n)（哈希表 + 递归栈）
