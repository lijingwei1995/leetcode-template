最大子数组和

中等 LeetCode 原题 ↗
主模板Kadane 算法→

题目

给你一个整数数组 nums，请找出和最大的连续子数组（子数组最少包含一个元素），返回其最大和。数组长度至少为 1，元素可能为负数。

示例 1
输入nums = [-2,1,-3,4,-1,2,1,-5,4]
输出6
示例 2
输入nums = [5,4,-1,7,8]
输出23

思路

cur 定义为“以当前元素结尾的最大子数组和”：要么接上以 i-1 结尾的那段，要么从 x 重新开始，信号是只依赖前一个状态，套 Kadane 模板滚动推进。变化点在于转移方程 max(x, cur + x)，另用 best 记录全程最大值作为答案。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def maxSubArray(self, nums):3        cur = best = nums[0]                       # 变化点: 从首元素起步，全负也不出错4        for x in nums[1:]:5            cur = max(x, cur + x)                  # 变化点: 接上前一段或从 x 重新开始6            best = max(best, cur)7        return best

变化点代码

  • L3

    从首元素起步，全负也不出错

  • L5

    接上前一段或从 x 重新开始

易错点

  • 01

    cur 从 nums[0] 起步而不是 0，全负数组要返回最大的单个元素

  • 02

    best 必须随 cur 同步更新，只在循环外取 cur 会漏掉中段最优值

  • 03

    cur 的语义是“以当前元素结尾”，它是过程量，答案永远是 best

复杂度

时间复杂度O(n)
空间复杂度O(1)
