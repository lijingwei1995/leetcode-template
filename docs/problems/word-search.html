题目

给定 m×n 的网格 board 和一个字符串单词 word，如果 word 存在于网格中返回 true，否则返回 false。单词必须由网格中相邻（上下左右）的字母按顺序构成，同一个单元格的字母不允许在单词中重复使用。

示例 1
输入board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
输出true
示例 2
输入board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCB"
输出false

思路

从每个格子尝试匹配 word 的第 k 个字符，匹配则向四邻推进第 k+1 个，这是网格 DFS 与回溯的合体：占位标记防回头，递归结束后恢复原字符。变化点在于 DFS 参数带匹配进度 k，k 走到词尾即宣告成功；外层必须枚举所有格子作为起点。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def exist(self, board, word):3        m, n = len(board), len(board[0])4 5        def dfs(i, j, k):6            if board[i][j] != word[k]:             # 变化点: 当前格必须匹配第 k 个字符7                return False8            if k == len(word) - 1:9                return True10            saved, board[i][j] = board[i][j], '#'  # 占位防回头11            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):12                ni, nj = i + di, j + dj13                if 0 <= ni < m and 0 <= nj < n and dfs(ni, nj, k + 1):14                    board[i][j] = saved            # 变化点: 成功路径也要恢复原字符15                    return True16            board[i][j] = saved                    # 变化点: 失败时撤销占位17            return False18 19        for i in range(m):20            for j in range(n):21                if dfs(i, j, 0):22                    return True23        return False

变化点代码

  • L6

    当前格必须匹配第 k 个字符

  • L14

    成功路径也要恢复原字符

  • L16

    失败时撤销占位

易错点

  • 01

    占位符 '#' 要在四方向递归之后恢复，否则会挡住兄弟分支与后续起点

  • 02

    匹配成功同样要恢复原字符再返回，外层还在继续枚举起点

  • 03

    起点必须枚举所有格子，只从 (0,0) 开始会漏解

复杂度

时间复杂度O(mn·3^L)，L 为单词长度
空间复杂度O(L)（递归栈）
