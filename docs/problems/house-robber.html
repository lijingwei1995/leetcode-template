打家劫舍

中等 LeetCode 原题 ↗
主模板线性 DP→

题目

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内的现金为非负整数，相邻房屋装有互相连通的防盗系统，如果两间相邻的房屋在同一晚被闯入，系统会自动报警。求在不触动报警的情况下，一晚能够偷窃到的最高金额。

示例 1
输入nums = [1,2,3,1]
输出4
示例 2
输入nums = [2,7,9,3,1]
输出12

思路

每个房屋只有“偷”与“不偷”两种选择，且只与前两间房的状态有关，是线性 DP 的信号。dp[i] 表示前 i 间房的最大金额：不偷第 i 间为 dp[i-1]，偷则为 dp[i-2]+nums[i]。变化点在于用两个滚动变量保存前两项，省掉数组。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def rob(self, nums):3        prev, cur = 0, 04        for x in nums:5            prev, cur = cur, max(cur, prev + x)   # 变化点: 偷当前房要跳过前一间6        return cur

变化点代码

  • L5

    偷当前房要跳过前一间

易错点

  • 01

    prev 与 cur 的更新必须同时完成，否则会用到已覆盖的值

  • 02

    只有一间房时答案就是它本身，空数组返回 0

  • 03

    金额非负，但不要假设一定能偷到所有正数房屋

复杂度

时间复杂度O(n)
空间复杂度O(1)
