两数之和

题目

给定一个整数数组 nums 和一个整数目标值 target，请在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案，同一个元素不能被重复使用，可以按任意顺序返回答案。

示例 1
输入nums = [2,7,11,15], target = 9
输出[0,1]
示例 2
输入nums = [3,2,4], target = 6
输出[1,2]

思路

在无序数组里为当前值找配对，是哈希映射“先查再存”的信号：遍历时先查补数 target - x 是否出现过，命中即返回两个下标。变化点在 key/value 的语义——值到下标的映射，以及先查后存的顺序避免自己配自己。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def twoSum(self, nums, target):3        seen = {}4        for i, x in enumerate(nums):5            if target - x in seen:              # 变化点: 先查“补数”是否出现过6                return [seen[target - x], i]7            seen[x] = i                         # 变化点: 值 -> 下标的映射语义8        return []

变化点代码

  • L5

    先查“补数”是否出现过

  • L7

    值 -> 下标的映射语义

易错点

  • 01

    先查补数再存当前值，顺序颠倒会出现同一元素配自己

  • 02

    返回 [seen[补数], i]，先出现的下标在前

  • 03

    题目保证有唯一解，兜底返回空列表仅为语法完整

时间复杂度O(n)
