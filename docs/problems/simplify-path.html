简化路径

题目

给你一个 Unix 风格的绝对路径 path，请你将其简化为规范路径。规范路径需满足：以单个 '/' 开头；任意两个目录名之间只有一个 '/'，目录名后不跟 '/'（根目录除外）；'.' 表示当前目录本身，'..' 表示将目录切换到上一级（根目录的上一级仍是根目录）；多个连续 '/' 视为单个 '/'。

示例 1
输入path = "/home//foo/"
输出"/home/foo"
示例 2
输入path = "/a/./b/../../c/"
输出"/c"

思路

路径化简是栈 + 字符串扫描的信号：按 '/' 切分段落逐段处理，空段与 '.' 跳过，'..' 弹栈回退上一级，其余入栈。变化点在 '..' 弹栈前要判空（根目录再回退仍是根），最后用 '/' 拼接并补上开头的 '/'。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def simplifyPath(self, path):3        stack = []4        for part in path.split('/'):            # 变化点: 按 / 切分逐段扫描5            if part == '' or part == '.':6                continue7            if part == '..':8                if stack:9                    stack.pop()                 # 变化点: .. 回退上一级，弹栈前判空10            else:11                stack.append(part)12        return '/' + '/'.join(stack)            # 变化点: 拼接时补开头斜杠

变化点代码

  • L4

    按 / 切分逐段扫描

  • L9

    .. 回退上一级，弹栈前判空

  • L12

    拼接时补开头斜杠

易错点

  • 01

    空段与 '.' 都要跳过：切分产生的空串对应连续斜杠

  • 02

    '..' 在栈空时直接忽略，根目录再回退仍是根目录

  • 03

    "..." 是合法目录名，不要当成回退处理

时间复杂度O(n)
空间复杂度O(n)
