环形链表

简单 LeetCode 原题 ↗
主模板快慢指针→

题目

给你一个链表的头节点 head，判断链表中是否有环。如果链表中存在环，则通过连续跟踪 next 指针可以再次到达某个节点；pos 表示尾节点连接到链表中的位置（从 0 开始计数），pos = -1 表示没有环。如果链表中存在环，返回 true；否则返回 false。

示例 1
输入head = [3,2,0,-4], pos = 1
输出true（尾节点连接到下标 1 的节点）
示例 2
输入head = [1], pos = -1
输出false

思路

判环是快慢指针的信号：slow 每走一步、fast 每走两步，有环则两者必然相遇，无环则 fast 先到空。变化点在循环条件先判 fast 与 fast.next 非空，并用 is 判断是否同一节点。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def hasCycle(self, head):3        slow = fast = head4        while fast and fast.next:5            slow = slow.next6            fast = fast.next.next               # 变化点: fast 每次两步制造速度差7            if slow is fast:                    # 变化点: is 判断是否同一节点8                return True9        return False

变化点代码

  • L6

    fast 每次两步制造速度差

  • L7

    is 判断是否同一节点

易错点

  • 01

    循环条件先判 fast 再判 fast.next，两步走的指针才不会越界

  • 02

    判断相遇用 is（同一节点对象），而不是比较值

  • 03

    空链表或单节点无环时循环不进入，直接返回 False

复杂度

时间复杂度O(n)
空间复杂度O(1)
