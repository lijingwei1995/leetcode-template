零钱兑换

题目

给定不同面额的硬币 coins 和总金额 amount，计算凑成总金额所需的最少硬币个数。如果没有任何组合能凑成该金额，返回 -1。每种硬币的数量是无限的。

示例 1
输入coins = [1,2,5], amount = 11
输出3
示例 2
输入coins = [2], amount = 3
输出-1

思路

每种硬币可用无限次，是典型的完全背包求最小值。dp[j] 表示凑出金额 j 的最少硬币数，转移为 dp[j] = min(dp[j], dp[j-coin]+1)。变化点在于容量正序遍历以允许重复使用硬币，以及用 amount+1 代替无穷大避免溢出。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def coinChange(self, coins, amount):3        INF = amount + 14        dp = [INF] * (amount + 1)5        dp[0] = 06        for coin in coins:7            for j in range(coin, amount + 1):        # 变化点: 完全背包正序遍历8                dp[j] = min(dp[j], dp[j - coin] + 1)9        return -1 if dp[amount] == INF else dp[amount]

变化点代码

  • L7

    完全背包正序遍历

易错点

  • 01

    dp 其余位置要初始化为无穷大，不能初始化为 0

  • 02

    金额为 0 时答案是 0，不是 -1

  • 03

    容量必须正序遍历，倒序会退化成 0-1 背包

复杂度

时间复杂度O(amount × 硬币种数)
空间复杂度O(amount)
