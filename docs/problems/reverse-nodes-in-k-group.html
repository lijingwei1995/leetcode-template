K 个一组翻转链表

困难 LeetCode 原题 ↗
主模板链表反转→相关模板链表哨兵与遍历→

题目

给你链表的头节点 head，每 k 个节点一组进行翻转，请你返回修改后的链表。节点总数不是 k 的整数倍时，请将最后剩余的节点保持原有顺序。你不能只是单纯的改变节点内部的值，而需要实际进行节点交换。

示例 1
输入head = [1,2,3,4,5], k = 2
输出[2,1,4,3,5]
示例 2
输入head = [1,2,3,4,5], k = 3
输出[3,2,1,4,5]

思路

K 个一组翻转是链表反转的信号：先探明本组是否凑够 k 个节点，够则把这一段反转并接回前后组，不够保持原样退出。变化点在反转的边界是下一组头 nxt_group 而不是 None，以及上一组尾要前移为下一组的哨兵。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def reverseKGroup(self, head, k):3        dummy = ListNode(0, head)4        prev_group = dummy5        while True:6            node = prev_group7            for _ in range(k):                  # 变化点: 先探明本组是否够 k 个8                node = node.next9                if not node:10                    return dummy.next11            group_end = prev_group.next         # 本组头，反转后成组尾12            nxt_group = node.next13            prev, cur = nxt_group, group_end    # 变化点: 反转以 nxt_group 为界而非 None14            for _ in range(k):15                nxt = cur.next16                cur.next = prev17                prev = cur18                cur = nxt19            prev_group.next = prev              # 前一组接新组头20            group_end.next = nxt_group21            prev_group = group_end              # 变化点: 本组尾成为下一组的哨兵

变化点代码

  • L7

    先探明本组是否够 k 个

  • L13

    反转以 nxt_group 为界而非 None

  • L21

    本组尾成为下一组的哨兵

易错点

  • 01

    先探明整组节点是否够 k 个再动手，反转到一半发现不足无法回退

  • 02

    反转段的终点是下一组头 nxt_group，写成 None 会把后面已反转的组接错

  • 03

    处理完一组后 prev_group 要前移到本组尾（原组头），否则下一组挂错位置

时间复杂度O(n)
空间复杂度O(1)
