二叉树中的最大路径和

困难 LeetCode 原题 ↗
主模板二叉树递归→

题目

二叉树中的路径定义为节点序列中每对相邻节点之间都存在边，且每个节点至多出现一次；路径至少包含一个节点，不必经过根节点。路径和是路径中各节点值的总和。给定根节点 root，返回最大路径和。节点值可能为负。

示例 1
输入root = [1,2,3]
输出6
示例 2
输入root = [-10,9,20,null,null,15,7]
输出42

思路

信号是“答案要在每个节点处汇总拐点路径”，套树递归模板：递归返回“从当前节点向下延伸的单向最大贡献”。左右贡献为负则弃用取 0；用当前值加左右两条贡献更新全局答案（可同时吃两条腿），但上抛时只能选一条。变化点：更新答案与返回贡献是两条线，返回值取 max(left, right)。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def maxPathSum(self, root):3        self.ans = float("-inf")4 5        def gain(node):6            if not node:7                return 08            left = max(gain(node.left), 0)        # 变化点: 子树贡献为负时弃用9            right = max(gain(node.right), 0)10            self.ans = max(self.ans, node.val + left + right)   # 变化点: 以当前节点为拐点更新答案11            return node.val + max(left, right)    # 变化点: 上抛只带一条腿，路径不能分叉12 13        gain(root)14        return self.ans

变化点代码

  • L8

    子树贡献为负时弃用

  • L10

    以当前节点为拐点更新答案

  • L11

    上抛只带一条腿，路径不能分叉

易错点

  • 01

    节点值可能为负，贡献要与 0 取 max 再参与计算

  • 02

    全局答案初始化为 -inf，全负树的答案是最大负值而不是 0

  • 03

    上抛贡献不能同时加左右，否则路径在当前节点分叉

复杂度

时间复杂度O(n)
空间复杂度O(h)（最坏 O(n)）
