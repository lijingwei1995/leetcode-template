移除元素

简单 LeetCode 原题 ↗
主模板同向双指针（读写指针）→

题目

给你一个数组 nums 和一个值 val，你需要原地移除所有数值等于 val 的元素，并返回移除后数组的新长度。元素的顺序可以改变，你不需要考虑数组中超出新长度后面的元素。

示例 1
输入nums = [3,2,2,3], val = 3
输出2, nums 前缀 = [2,2]
示例 2
输入nums = [0,1,2,2,3,0,4,2], val = 2
输出5, nums 前缀 = [0,1,3,0,4]

思路

要求原地删除且 O(1) 空间，是同向读写双指针的信号：read 指针扫描全部元素，write 指向下一个可写位置。nums[read] != val 时把 read 处的值写到 write 并让 write 前移。变化点只在保留条件——不等于 val 的元素全部留下，扫描结束时 write 就是新长度。

识别信号→ 套用模板→ 调整变化点

易错点

  • 01

    write 起点是 0，别初始化成 1，首个元素也可能被保留

  • 02

    返回值是 write（新长度），不是 len(nums) 或 write + 1

  • 03

    题目允许改变元素顺序，所以不需要交换，直接覆盖即可
