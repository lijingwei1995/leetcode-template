实现 Trie (前缀树)

中等 LeetCode 原题 ↗
主模板字典树→相关模板数据结构设计→

题目

请实现 Trie（前缀树）类，包含三个方法：Trie() 初始化前缀树对象；insert(word) 向树中插入字符串 word；search(word) 判断 word 是否在树中（必须是完整插入过的单词）；startsWith(prefix) 判断之前插入的字符串中是否存在以 prefix 为前缀的字符串。所有输入仅由小写英文字母组成。

示例 1
输入操作 ["Trie","insert","search","search","startsWith","insert","search"]，参数 [[],["apple"],["apple"],["app"],["app"],["app"],["app"]]
输出[null,null,true,false,true,null,true]
示例 2
输入操作 ["Trie","insert","search","startsWith"]，参数 [[],["app"],["ap"],["ap"]]
输出[null,null,false,true]

思路

“公共前缀共享一条路径”是字典树的信号，套字典树模板：节点持有 children 映射与 end 标记，insert 沿字符逐层建节点、末尾打标记。变化点在于查询语义分两档——search 走完路径还要求 end 为真，startsWith 只要路径走得通即可；两者复用同一个按字符下行的查找。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Trie:2    def __init__(self):3        self.children = {}4        self.end = False                           # 变化点: end 标记区分“前缀存在”与“单词完整”5 6    def insert(self, word):7        node = self8        for ch in word:9            if ch not in node.children:10                node.children[ch] = Trie()         # 变化点: 沿字符逐层建节点11            node = node.children[ch]12        node.end = True13 14    def search(self, word):15        node = self._walk(word)16        return node is not None and node.end       # 变化点: 完整单词要求 end 为真17 18    def startsWith(self, prefix):19        return self._walk(prefix) is not None20 21    def _walk(self, s):22        node = self23        for ch in s:24            if ch not in node.children:25                return None26            node = node.children[ch]27        return node

变化点代码

  • L4

    end 标记区分“前缀存在”与“单词完整”

  • L10

    沿字符逐层建节点

  • L16

    完整单词要求 end 为真

易错点

  • 01

    search 与 startsWith 的唯一区别是 end 标记，存在前缀但没打标记时 search 必须返回 False

  • 02

    insert 只在子节点缺失时新建，已有路径直接走下去，覆盖节点会丢掉其它单词

  • 03

    三个方法都从根（self）出发按字符下行，查不到边就返回 None/False

复杂度

时间复杂度insert / search / startsWith 每次 O(L)，L 为字符串长度
空间复杂度O(总插入字符数)
