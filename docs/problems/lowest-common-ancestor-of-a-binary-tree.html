二叉树的最近公共祖先

中等 LeetCode 原题 ↗
主模板二叉树递归→

题目

给定二叉树和其中两个节点 p、q，找到它们的最近公共祖先。最近公共祖先是同时为 p 和 q 的祖先且深度最大的节点（一个节点可以是它自己的祖先）。所有节点值唯一，且 p、q 都存在于树中。

示例 1
输入root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出3
示例 2
输入root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出5

思路

后序递归自底向上汇聚信息是本题信号，套树递归模板：递归返回“子树中是否命中 p 或 q”。命中目标或空节点直接上抛；左右子树各命中一个时，当前节点就是最近公共祖先；只有一侧命中就继续上抛那一侧。变化点：返回的是节点对象而非布尔值，命中判定用 is 比较节点身份。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def lowestCommonAncestor(self, root, p, q):3        if not root or root is p or root is q:    # 变化点: 命中目标节点直接上抛4            return root5        left = self.lowestCommonAncestor(root.left, p, q)6        right = self.lowestCommonAncestor(root.right, p, q)7        if left and right:                        # 变化点: 两侧各命中一个，当前即 LCA8            return root9        return left or right

变化点代码

  • L3

    命中目标节点直接上抛

  • L7

    两侧各命中一个，当前即 LCA

易错点

  • 01

    命中判定要用 root is p 节点身份比较，不要按值新建节点

  • 02

    一个节点可以是另一个的祖先，递归基必须先判 root is p or root is q

  • 03

    p、q 保证存在，无需处理找不到的情况，答案只可能是 p、q 或真正的分叉点

复杂度

时间复杂度O(n)
空间复杂度O(h)（最坏 O(n)）
