交错字符串

中等 LeetCode 原题 ↗
主模板字符串 DP→

题目

给定三个字符串 s1、s2 和 s3，判断 s3 是否由 s1 和 s2 交错组成。交错的定义是 s1 和 s2 的字符按原顺序交替出现，但同一字符串内部字符的相对顺序不能改变。

示例 1
输入s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"
输出true
示例 2
输入s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"
输出false

思路

s3 的每个前缀都由 s1 的某个前缀和 s2 的某个前缀拼成，状态是二维的，但可以滚动成一维。dp[j] 表示用 s1 的前 i 个字符和 s2 的前 j 个字符能否拼出 s3 的前 i+j 个字符。变化点在于当前字符既可能来自 s1，也可能来自 s2。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def isInterleave(self, s1, s2, s3):3        m, n = len(s1), len(s2)4        if m + n != len(s3):5            return False6        dp = [False] * (n + 1)7        dp[0] = True8        for j in range(1, n + 1):9            dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]   # 变化点: 只取 s2 的前缀10        for i in range(1, m + 1):11            dp[0] = dp[0] and s1[i - 1] == s3[i - 1]12            for j in range(1, n + 1):13                from_s1 = dp[j] and s1[i - 1] == s3[i + j - 1]14                from_s2 = dp[j - 1] and s2[j - 1] == s3[i + j - 1]15                dp[j] = from_s1 or from_s2              # 变化点: 两个来源任一可达16        return dp[n]

变化点代码

  • L9

    只取 s2 的前缀

  • L15

    两个来源任一可达

易错点

  • 01

    先判断长度，长度不匹配直接返回 False

  • 02

    滚动数组中 dp[j] 更新前代表上一行，dp[j-1] 代表当前行左邻

  • 03

    s1 或 s2 为空时，另一个必须与 s3 完全相同

复杂度

时间复杂度O(mn)
空间复杂度O(n)
