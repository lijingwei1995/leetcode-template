逆波兰表达式求值

中等 LeetCode 原题 ↗
主模板栈与表达式→

题目

给你一个字符串数组 tokens，表示一个根据逆波兰表示法（后缀表达式）表示的算术表达式。请你计算该表达式，返回一个整数。有效运算符为 '+'、'-'、'*'、'/'；除法运算向零截断；表达式中不含除零运算；结果及中间计算结果均为 32 位整数。

示例 1
输入tokens = ["2","1","+","3","*"]
输出9（(2 + 1) * 3）
示例 2
输入tokens = ["4","13","5","/","+"]
输出6（4 + (13 / 5)）

思路

后缀表达式求值是栈与表达式的信号：数字直接入栈，遇运算符弹出两个操作数、结算后把结果压回，扫描结束栈中唯一元素即答案。变化点在弹出顺序——先弹的是右操作数 b、后弹的是左操作数 a，且除法要用 int(a/b) 向零截断而非 //。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def evalRPN(self, tokens):3        stack = []4        for t in tokens:5            if t in '+-*/':6                b = stack.pop()                 # 变化点: 先弹的是右操作数，注意运算顺序7                a = stack.pop()8                if t == '+':9                    stack.append(a + b)10                elif t == '-':11                    stack.append(a - b)12                elif t == '*':13                    stack.append(a * b)14                else:15                    stack.append(int(a / b))    # 变化点: 除法向零截断，不能用 //16            else:17                stack.append(int(t))18        return stack[0]

变化点代码

  • L6

    先弹的是右操作数，注意运算顺序

  • L15

    除法向零截断，不能用 //

易错点

  • 01

    操作数顺序：a - b、a / b 中 a 是先入栈的那个，弹反了结果就错

  • 02

    除法截断方向：int(a/b) 向零取整，-7 / 2 得 -3；用 // 会得到 -4

  • 03

    负数字符串如 "-11" 不是运算符，用 int(t) 转换即可；判断运算符别用 len(t) == 1

复杂度

时间复杂度O(n)
空间复杂度O(n)
