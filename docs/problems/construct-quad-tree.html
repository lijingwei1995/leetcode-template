建立四叉树

中等 LeetCode 原题 ↗
主模板分治→

题目

给你一个 n×n 的矩阵 grid（n 是 2 的幂），请为它建立四叉树：若当前区域的值全部相同，建一个 isLeaf 为 True、val 为该值的叶子节点；否则建 isLeaf 为 False 的内部节点，把区域四等分（左上、右上、左下、右下），依次递归为四个子节点。

示例 1
输入grid = [[0,1],[1,0]]
输出内部节点，四个叶子依次为 [0],[1],[1],[0]
示例 2
输入grid = [[1,1],[1,1]]
输出单个叶子节点 [1]

思路

四叉树是二维分治：大区域可拆成四个同构小区域，信号正是分治模板的“拆分方式与合并”。变化点在于同值判定先行——先检查整块区域是否同值，同值建叶子返回，否则四等分递归；内部节点的 val 无意义，填任意值即可。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def construct(self, grid):3        n = len(grid)4 5        def same(r, c, size):6            val = grid[r][c]7            for i in range(r, r + size):8                for j in range(c, c + size):9                    if grid[i][j] != val:10                        return False11            return True12 13        def build(r, c, size):14            if same(r, c, size):                   # 变化点: 区域同值合并为叶子15                return Node(grid[r][c] == 1, True, None, None, None, None)16            half = size // 217            return Node(True, False,               # 变化点: 四象限递归，内部 val 任意18                        build(r, c, half),19                        build(r, c + half, half),20                        build(r + half, c, half),21                        build(r + half, c + half, half))22 23        return build(0, 0, n)

变化点代码

  • L14

    区域同值合并为叶子

  • L17

    四象限递归，内部 val 任意

易错点

  • 01

    先判同值再划分，顺序颠倒会把本可合并的区域错误细分

  • 02

    四个象限的起点别写混：(r,c)、(r,c+half)、(r+half,c)、(r+half,c+half)

  • 03

    内部节点 isLeaf 必须为 False，val 按惯例填 True 等任意值

复杂度

时间复杂度O(n² log n)
空间复杂度O(log n)（递归栈，不计输出树）
