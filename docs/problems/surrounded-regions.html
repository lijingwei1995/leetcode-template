被围绕的区域

中等 LeetCode 原题 ↗
主模板网格 DFS / FloodFill→

题目

给你一个 m×n 的矩阵 board，由若干字符 'X' 和 'O' 组成，请捕获所有被围绕的区域：把被围绕区间里的所有 'O' 用 'X' 填充。任何不在边界上、或不与边界上的 'O' 相连的 'O' 最终都会被填充为 'X'；与边界连通的 'O' 保持不变。要求原地修改，无需返回值。

示例 1
输入board = [['X','X','X','X'],['X','O','O','X'],['X','X','O','X'],['X','O','X','X']]
输出[['X','X','X','X'],['X','X','X','X'],['X','X','X','X'],['X','O','X','X']]
示例 2
输入board = [['X']]
输出[['X']]

思路

正向判断“是否被围”无从下手，反过来想：被 'X' 包住的 'O' 一定不与边界相连。信号仍是网格 DFS，但方向反转——只从四条边界上的 'O' 出发反向 DFS，把边界连通的 'O' 临时标记成 '#'；最后扫全表，把残余 'O' 置 'X'、把 '#' 还原成 'O'。变化点就在于“从边界反向标记”这一思维转换。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def solve(self, board):3        m, n = len(board), len(board[0])4 5        def dfs(i, j):6            if not (0 <= i < m and 0 <= j < n) or board[i][j] != 'O':7                return8            board[i][j] = '#'                      # 变化点: 边界可达的 O 临时标记为 #9            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):10                dfs(i + di, j + dj)11 12        for i in range(m):                         # 变化点: 只从四条边界的 O 反向出发13            dfs(i, 0)14            dfs(i, n - 1)15        for j in range(n):16            dfs(0, j)17            dfs(m - 1, j)18 19        for i in range(m):                         # 变化点: 一次遍历用 if/elif 同时翻转与还原20            for j in range(n):21                if board[i][j] == 'O':22                    board[i][j] = 'X'23                elif board[i][j] == '#':24                    board[i][j] = 'O'

变化点代码

  • L8

    边界可达的 O 临时标记为 #

  • L12

    只从四条边界的 O 反向出发

  • L19

    一次遍历用 if/elif 同时翻转与还原

易错点

  • 01

    占位符必须用 '#' 这类第三方字符，直接改成 'X' 会破坏边界连通性判断

  • 02

    收尾的翻转与还原在同一次遍历里用 if/elif 完成，改过的格子不能再被二次判断

  • 03

    DFS 起点只有边界的 O，若把内部 O 也当起点，被围区域会被误标成 '#'

复杂度

时间复杂度O(mn)
空间复杂度O(mn)（递归栈，最坏情况）
