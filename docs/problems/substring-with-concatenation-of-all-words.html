串联所有单词的子串

困难 LeetCode 原题 ↗
主模板滑动窗口→

题目

给定一个字符串 s 和一个字符串数组 words，words 中所有字符串长度相同。串联子串是指一个包含 words 中所有字符串以任意顺序排列连接起来的子串，且每个字符串恰好出现一次（按 words 中的次数使用）。返回 s 中所有串联子串的起始索引，顺序不重要。

示例 1
输入s = "barfoothefoobarman", words = ["foo","bar"]
输出[0,9]
示例 2
输入s = "barfoofoobarthefoobarman", words = ["bar","foo","the"]
输出[6,9,12]

思路

窗口单位是等长单词而非字符，滑动窗口信号：以单词长度 wl 为步长、按 wl 个余数分通道滑动，哈希计数维护窗口内单词。超量的单词从左侧按单词粒度弹出。变化点在于按余数分 wl 条通道，命中条件是窗口跨度恰等于 wl × 单词数。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def findSubstring(self, s, words):3        need = {}4        for w in words:5            need[w] = need.get(w, 0) + 16        wl, count = len(words[0]), len(words)7        total = wl * count8        result = []9        for offset in range(wl):                # 变化点: 按余数分 wl 条滑动通道10            left, have = offset, {}11            for right in range(offset, len(s) - wl + 1, wl):12                word = s[right:right + wl]13                have[word] = have.get(word, 0) + 114                while have[word] > need.get(word, 0):   # 变化点: 超额单词从左侧按词粒度弹出15                    left_word = s[left:left + wl]16                    have[left_word] -= 117                    left += wl18                if right + wl - left == total:  # 变化点: 窗口跨度恰等于单词总长即命中19                    result.append(left)20        return result

变化点代码

  • L9

    按余数分 wl 条滑动通道

  • L14

    超额单词从左侧按词粒度弹出

  • L18

    窗口跨度恰等于单词总长即命中

易错点

  • 01

    必须按 wl 个余数分别起窗，只从下标 0 开始会漏掉对齐在其他余数上的解

  • 02

    words 里可能有重复单词，need 要累加计数而不是简单去重

  • 03

    右端上限是 len(s) - wl + 1，切片 s[right:right+wl] 才不会截到残缺词

复杂度

时间复杂度O(n·wl)（n 为 s 长度，wl 为单词长度）
空间复杂度O(m·wl)（m 为 words 单词数）
