编辑距离

中等 LeetCode 原题 ↗
主模板字符串 DP→

题目

给你两个单词 word1 和 word2，请返回将 word1 转换成 word2 所使用的最少操作数。允许的操作有插入一个字符、删除一个字符、替换一个字符。

示例 1
输入word1 = "horse", word2 = "ros"
输出3
示例 2
输入word1 = "intention", word2 = "execution"
输出5

思路

两个字符串的前缀之间的编辑距离只依赖更短前缀，是经典字符串 DP。dp[i][j] 表示 word1 前 i 个字符转成 word2 前 j 个字符的最少操作数：末字符相同则继承左上，否则在删、增、替换中取最小加一。变化点在于滚动数组保存左上角。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def minDistance(self, word1, word2):3        m, n = len(word1), len(word2)4        dp = list(range(n + 1))5        for i in range(1, m + 1):6            prev = dp[0]7            dp[0] = i8            for j in range(1, n + 1):9                temp = dp[j]10                if word1[i - 1] == word2[j - 1]:11                    dp[j] = prev                        # 变化点: 末字符相同，无需操作12                else:13                    dp[j] = min(dp[j], dp[j - 1], prev) + 1  # 变化点: 删 / 增 / 替换14                prev = temp15        return dp[n]

变化点代码

  • L11

    末字符相同，无需操作

  • L13

    删 / 增 / 替换

易错点

  • 01

    dp[0] 要初始化为 i，表示把前 i 个字符全部删除

  • 02

    prev 必须在覆盖 dp[j] 之前保存，它代表左上角

  • 03

    两个空串的编辑距离为 0

复杂度

时间复杂度O(mn)
空间复杂度O(n)
