二叉搜索树迭代器

中等 LeetCode 原题 ↗
主模板BST 中序遍历→相关模板数据结构设计→

题目

实现一个二叉搜索树迭代器类 BSTIterator，表示按中序遍历 BST 的迭代器：初始化传入根节点；next() 返回中序遍历的下一个最小数；hasNext() 判断是否还有下一个数。要求两者平均时间 O(1)，空间 O(h)，h 为树高。

示例 1
输入inputs = ["BSTIterator","next","next","hasNext","next","hasNext","next","hasNext","next","hasNext","next","hasNext"], root = [7,3,15,null,null,9,20]
输出[null,3,7,true,9,true,15,true,20,false]

思路

“中序遍历惰性化”指向 BST 中序模板：用栈保存最左链，栈顶就是下一个最小节点。next() 弹出栈顶后把其右子树的最左链压栈，遍历状态一次只推进一小段。变化点：构造函数只压根的最左链而不全量遍历，next() 的摊还成本才是 O(1)。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class BSTIterator:2    def __init__(self, root):3        self.stack = []4        self._push_left(root)                     # 变化点: 初始化只压最左链，惰性遍历5 6    def _push_left(self, node):7        while node:8            self.stack.append(node)9            node = node.left10 11    def next(self):12        node = self.stack.pop()13        if node.right:                            # 变化点: 弹出后压入右子树的最左链14            self._push_left(node.right)15        return node.val16 17    def hasNext(self):18        return bool(self.stack)

变化点代码

  • L4

    初始化只压最左链，惰性遍历

  • L13

    弹出后压入右子树的最左链

易错点

  • 01

    构造函数不要把整棵树遍历成数组，会超出 O(h) 空间要求

  • 02

    next() 弹栈后若右子树非空，必须把右子树最左链压入，否则中序断链

  • 03

    hasNext() 判断栈是否非空，不要另设游标变量造成状态不一致

复杂度

时间复杂度next 均摊 O(1)
空间复杂度O(h)
