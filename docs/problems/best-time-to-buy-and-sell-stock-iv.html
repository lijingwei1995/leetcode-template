买卖股票的最佳时机 IV

困难 LeetCode 原题 ↗
主模板股票买卖 DP→

题目

给定数组 prices 和整数 k，其中 prices[i] 是某支股票第 i 天的价格。你最多可以完成 k 笔交易，求能获得的最大利润。注意不能同时参与多笔交易。

示例 1
输入k = 2, prices = [2,4,1]
输出2
示例 2
输入k = 2, prices = [3,2,6,5,0,3]
输出7

思路

在股票状态机 DP 上增加交易次数维度：buy[j] 表示最多 j 笔交易时持股的最大收益，sell[j] 表示不持股。每天先更新买入再更新卖出。变化点在于 k 很大时，k 超过 n/2 会退化为无限次交易，需单独处理避免超时。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def maxProfit(self, k, prices):3        if not prices or k == 0:4            return 05        n = len(prices)6        if k >= n // 2:                       # 变化点: 次数足够多，退化为无限次交易7            return sum(max(0, prices[i] - prices[i - 1]) for i in range(1, n))8        buy = [-float('inf')] * (k + 1)9        sell = [0] * (k + 1)10        for p in prices:11            for j in range(1, k + 1):         # 变化点: 枚举交易次数12                buy[j] = max(buy[j], sell[j - 1] - p)13                sell[j] = max(sell[j], buy[j] + p)14        return sell[k]

变化点代码

  • L6

    次数足够多，退化为无限次交易

  • L11

    枚举交易次数

易错点

  • 01

    k 大于等于 n/2 时应走无限次交易的贪心分支

  • 02

    buy 数组初始化为负无穷，sell 初始化为 0

  • 03

    第二次买入要基于 sell[j-1]，不是 sell[j]

复杂度

时间复杂度O(nk)（k 过大时 O(n)）
空间复杂度O(k)
