题目

给定链表的头结点 head，请将其按节点值升序排列并返回排序后的链表头。要求时间复杂度为 O(n log n)；链表节点数在 [0, 5×10⁴] 范围内。

示例 1
输入head = [4,2,1,3]
输出[1,2,3,4]
示例 2
输入head = [-1,5,3,4,0]
输出[-1,0,3,4,5]

思路

链表不便随机访问、快排不占优，归并排序是 O(n log n) 的自然选择，信号是分治：快慢指针找中点断成两半，分别递归排序，再按“合并两个有序链表”方式拼接。变化点在于快指针先走一步让中点落在前半段、断链后再递归，合并阶段复用 dummy 头技巧。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def sortList(self, head):3        if not head or not head.next:4            return head5 6        slow, fast = head, head.next               # 变化点: fast 先走一步，中点必落前半段7        while fast and fast.next:8            slow = slow.next9            fast = fast.next.next10        mid = slow.next11        slow.next = None                           # 变化点: 断链后才能分别递归12 13        left = self.sortList(head)14        right = self.sortList(mid)15 16        dummy = cur = ListNode(0)                  # 变化点: 合并=拼接两个有序链表17        while left and right:18            if left.val <= right.val:19                cur.next, left = left, left.next20            else:21                cur.next, right = right, right.next22            cur = cur.next23        cur.next = left if left else right24        return dummy.next

变化点代码

  • L6

    fast 先走一步，中点必落前半段

  • L11

    断链后才能分别递归

  • L16

    合并=拼接两个有序链表

易错点

  • 01

    找中点时 fast 从 head.next 出发，两节点链表才切得开，否则死循环

  • 02

    slow.next = None 必须在两次递归之前执行，否则递归处理的仍是整条链

  • 03

    合并结束后把剩余部分 cur.next 接上，漏接会丢尾部节点

复杂度

时间复杂度O(n log n)
空间复杂度O(log n)（递归栈）
