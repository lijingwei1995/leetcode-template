二叉搜索树的最小绝对差

简单 LeetCode 原题 ↗
主模板BST 中序遍历→

题目

给定一棵二叉搜索树的根节点 root，树中节点值各不相同，返回树中任意两个不同节点值之间的最小差值。差值是一个正数，必须来自两个不同的节点。

示例 1
输入root = [4,2,6,1,3]
输出1
示例 2
输入root = [1,0,48,null,null,12,49]
输出1

思路

BST 中序遍历得到升序序列，最小差值只能出现在相邻两个值之间，套 BST 中序模板：递归左子树、与上一个值比较、更新 prev。变化点：维护全局 prev 记录上一个中序值，比较只需 O(1)，无需把整棵树先展开成数组再扫一遍。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def getMinimumDifference(self, root):3        self.prev = None4        self.ans = float("inf")5 6        def inorder(node):7            if not node:8                return9            inorder(node.left)10            if self.prev is not None:             # 变化点: 只比较相邻两个中序值11                self.ans = min(self.ans, node.val - self.prev)12            self.prev = node.val13            inorder(node.right)14 15        inorder(root)16        return self.ans

变化点代码

  • L10

    只比较相邻两个中序值

易错点

  • 01

    prev 用 is not None 判断，不能用真值判断，节点值可能为 0

  • 02

    中序严格递增，差值 node.val - prev 天然非负，无需 abs

  • 03

    最小差一定在相邻中序值之间，两两比较全部节点是多余功

复杂度

时间复杂度O(n)
空间复杂度O(h)（递归栈）
