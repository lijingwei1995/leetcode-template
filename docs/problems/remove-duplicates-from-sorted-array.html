删除有序数组中的重复项

简单 LeetCode 原题 ↗
主模板同向双指针（读写指针）→

题目

给你一个升序排列的数组 nums，请你原地删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。必须保持元素的相对顺序一致，返回后 nums 的前 k 个位置应恰好是去重后的结果。

示例 1
输入nums = [1,1,2]
输出2, nums 前缀 = [1,2]
示例 2
输入nums = [0,0,1,1,1,2,2,3,3,4]
输出5, nums 前缀 = [0,1,2,3,4]

思路

升序数组去重且要保持相对顺序，同向读写双指针信号：write 始终指向已保留部分的末尾。nums[read] 与上一个保留值 nums[write-1] 不同时才写入。变化点在于比较对象从 val 换成“上一个保留值”，且首个元素无条件保留、write 从 1 起步。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def removeDuplicates(self, nums):3        write = 1                               # 变化点: 首个元素必保留，write 从 1 起步4        for read in range(1, len(nums)):5            if nums[read] != nums[write - 1]:   # 变化点: 与上一个保留值比较，而不是与上一个原始值6                nums[write] = nums[read]7                write += 18        return write

变化点代码

  • L3

    首个元素必保留，write 从 1 起步

  • L5

    与上一个保留值比较，而不是与上一个原始值

易错点

  • 01

    比较对象是 nums[write-1]（上一个保留值），写成 nums[read-1] 会把中间的重复也误判

  • 02

    write 从 1 起步隐含数组非空，题目保证 1 <= len(nums)，不必额外判空

  • 03

    超出 write 的尾部元素不用清理，题目只校验前 k 个位置

复杂度

时间复杂度O(n)
空间复杂度O(1)
