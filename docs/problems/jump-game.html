跳跃游戏

中等 LeetCode 原题 ↗
主模板线性贪心→

题目

给你一个非负整数数组 nums，你最初位于数组的第一个下标。数组中每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标，如果能返回 true，否则返回 false。

示例 1
输入nums = [2,3,1,1,4]
输出true
示例 2
输入nums = [3,2,1,0,4]
输出false

思路

能否到达终点只取决于“当前位置之前能跳到的最远下标”，线性贪心信号：从左到右扫描，维护 farthest = max(farthest, i + nums[i])。一旦 i 超出 farthest，说明链条断裂、无法继续前进。变化点在于扫描只需到倒数第二个位置，且 i > farthest 时立即返回 False。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def canJump(self, nums):3        farthest = 04        for i in range(len(nums) - 1):          # 变化点: 只扫到倒数第二个位置即可判定5            if i > farthest:                    # 变化点: 当前位置已不可达，链条断裂6                return False7            farthest = max(farthest, i + nums[i])8        return farthest >= len(nums) - 1

变化点代码

  • L4

    只扫到倒数第二个位置即可判定

  • L5

    当前位置已不可达，链条断裂

易错点

  • 01

    扫描到 len(nums)-2 即可，扫到最后一个位置反而容易把“恰好停住”误处理

  • 02

    i > farthest 必须提前返回 False，继续更新会把不可达位置的跳跃范围混进来

  • 03

    单元素数组 range(0) 不进循环，farthest = 0 >= 0 返回 True，天然正确

复杂度

时间复杂度O(n)
空间复杂度O(1)
