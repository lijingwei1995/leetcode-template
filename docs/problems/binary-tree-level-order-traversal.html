二叉树的层序遍历

中等 LeetCode 原题 ↗
主模板层序遍历（BFS）→

题目

给定二叉树的根节点 root，返回其节点值的层序遍历结果：逐层、从左到右访问所有节点，结果按层分组为二维数组。

示例 1
输入root = [3,9,20,null,null,15,7]
输出[[3],[9,20],[15,7]]
示例 2
输入root = [1]
输出[[1]]

思路

本题就是层序模板本体：队列快照即一层，把快照中每个节点的值收集为一组，再把所有孩子收进新队列，直到队空。变化点在于模板本身：记住“整层快照处理”的写法，其余层序题都是在它上面做局部修改。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def levelOrder(self, root):3        if not root:4            return []5        res = []6        queue = [root]7        while queue:8            res.append([node.val for node in queue])   # 变化点: 队列快照即一整层9            queue = [c for node in queue for c in (node.left, node.right) if c]10        return res

变化点代码

  • L8

    队列快照即一整层

易错点

  • 01

    先把当前层的值收集完、再统一收下一层孩子，避免层间混杂

  • 02

    空树返回 []，不要返回 [[]]

  • 03

    列表推导收集孩子时要记得过滤 None

复杂度

时间复杂度O(n)
空间复杂度O(n)（队列）
