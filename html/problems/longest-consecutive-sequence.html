最长连续序列

中等 LeetCode 原题 ↗
主模板哈希映射→

题目

给定一个未排序的整数数组 nums，找出数字连续的最长序列（序列元素在原数组中不需要连续排列）的长度。请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1
输入nums = [100,4,200,1,3,2]
输出4（最长连续序列是 [1,2,3,4]）
示例 2
输入nums = [0,3,7,2,5,8,4,6,0,1]
输出9

思路

求最长连续序列且要求 O(n)，是哈希映射（集合）的信号：数字放进集合去重，只对“没有左邻居 x-1”的连续段起点向右扩展计数。变化点在起点判断——其余元素一律跳过，保证每段只被扫一次、总时间线性。

识别信号→ 套用模板→ 调整变化点

模板解法

1class Solution:2    def longestConsecutive(self, nums):3        num_set = set(nums)4        best = 05        for x in num_set:6            if x - 1 in num_set:                # 变化点: 有左邻居就不是段起点，跳过7                continue8            cur, length = x, 19            while cur + 1 in num_set:           # 变化点: 只从段起点向右扩展10                cur += 111                length += 112            best = max(best, length)13        return best

变化点代码

  • L6

    有左邻居就不是段起点，跳过

  • L9

    只从段起点向右扩展

易错点

  • 01

    先 set() 去重，否则重复元素会重复触发起点判断

  • 02

    没有“x-1 不在集合”的判断会退化成 O(n²)，这是本题 O(n) 的关键

  • 03

    空数组返回 0，best 初值为 0 而不是 1
