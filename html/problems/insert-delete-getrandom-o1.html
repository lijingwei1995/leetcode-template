O(1) 时间插入、删除和获取随机元素

中等 LeetCode 原题 ↗
主模板数据结构设计→相关模板哈希映射→

题目

实现 RandomizedSet 类：insert(val) 在元素不存在时向集合中插入该项并返回 true，否则返回 false；remove(val) 在元素存在时移除该项并返回 true，否则返回 false；getRandom() 等概率随机返回集合中的任意一项。要求每个函数的平均时间复杂度为 O(1)。集合中每个元素最多出现一次。

示例 1
输入insert(1)、remove(2)、insert(2)、getRandom()
输出true / false / true / 2（集合内为 [1,2]，各以 1/2 概率返回）
示例 2
输入remove(1)、insert(2)、getRandom()
输出true / false / 2

思路

要在 O(1) 内完成插入、删除与等概率随机取值，是“哈希映射 + 动态数组”的设计信号：字典负责 O(1) 定位，数组负责 O(1) 随机下标。删除时用尾元素覆盖被删位置再 pop，避免数组整体搬移。变化点在于“字典存值到下标映射 + 尾部覆盖删除”的组合，以及 getRandom 直接随机数组下标。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1import random2 3class RandomizedSet:4    def __init__(self):5        self.vals = []6        self.pos = {}                           # 变化点: 哈希表存“值 -> 数组下标”7 8    def insert(self, val):9        if val in self.pos:10            return False11        self.pos[val] = len(self.vals)12        self.vals.append(val)13        return True14 15    def remove(self, val):16        if val not in self.pos:17            return False18        i = self.pos[val]19        last = self.vals[-1]                    # 变化点: 用尾元素覆盖被删位置，O(1) 删除20        self.vals[i] = last21        self.pos[last] = i22        self.vals.pop()23        del self.pos[val]24        return True25 26    def getRandom(self):27        return random.choice(self.vals)         # 变化点: 随机数组下标即等概率

变化点代码

  • L6

    哈希表存“值 -> 数组下标”

  • L19

    用尾元素覆盖被删位置，O(1) 删除

  • L27

    随机数组下标即等概率

易错点

  • 01

    删除被删值恰是尾元素时，覆盖与 pop 的顺序仍要先改 pos 再 del，否则映射残留

  • 02

    只靠哈希表做不到 O(1) 等概率随机，必须配合数组下标

  • 03

    本题 LeetCode 签名是 RandomizedSet 而非 Solution，提交时类名要一致

复杂度

时间复杂度各操作平均 O(1)
空间复杂度O(n)
