接雨水

困难 LeetCode 原题 ↗

题目

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图 height，计算按此排列的柱子，下雨之后能接多少雨水。

示例 1
输入height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出6
示例 2
输入height = [4,2,0,3,2,5]
输出9

思路

每个位置能接的水由 min(左最高, 右最高) - 自身高度决定，对撞双指针信号：left、right 从两端内移，谁矮就结算谁——另一侧必有更高的墙兜底，水位无需再确认。变化点在于维护 left_max / right_max 两个滚动最大值，先更新再结算、结算后内移。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def trap(self, height):3        left, right = 0, len(height) - 14        left_max = right_max = 05        water = 06        while left < right:7            if height[left] < height[right]:    # 变化点: 结算较矮一侧，另一侧必有高墙兜底8                left_max = max(left_max, height[left])9                water += left_max - height[left]10                left += 111            else:12                right_max = max(right_max, height[right])13                water += right_max - height[right]14                right -= 115        return water

变化点代码

  • L7

    结算较矮一侧，另一侧必有高墙兜底

易错点

  • 01

    结算的是“较矮的一侧”，两侧高度相等时归入 right 分支即可，不影响正确性

  • 02

    left_max 要先更新再结算，顺序错了首根柱子会算出负水

  • 03

    height 为空时 right = -1，循环不进入直接返回 0，不用特判

复杂度

时间复杂度O(n)
空间复杂度O(1)
