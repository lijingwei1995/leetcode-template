Pow(x, n)

中等 LeetCode 原题 ↗
主模板分治→

题目

实现 pow(x, n)，即计算 x 的 n 次幂函数（x 为浮点数，n 为整数，可能为负）。不允许使用库函数 pow，且时间复杂度需低于 O(n)。

示例 1
输入x = 2.0, n = 10
输出1024.0
示例 2
输入x = 2.0, n = -2
输出0.25

思路

x^n = (x^(n/2))²，n 为奇数再补乘一个 x，是分治快速幂的信号；负指数先转成 1/x 的正指数幂。变化点在于递归按 exp//2 折半、返回前平方，再按指数奇偶补乘底数，指数每轮砍半只需 O(log n) 层。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def myPow(self, x, n):3        if n < 0:4            x, n = 1 / x, -n                    # 变化点: 负指数转倒数5        def qpow(base, exp):6            if exp == 0:7                return 1.08            half = qpow(base, exp // 2)         # 变化点: 指数折半递归9            return half * half * (base if exp % 2 else 1)   # 变化点: 平方后按奇偶补乘10        return qpow(x, n)

变化点代码

  • L4

    负指数转倒数

  • L8

    指数折半递归

  • L9

    平方后按奇偶补乘

易错点

  • 01

    负指数先转 1/x；Python 中 -2^31 取负不会溢出，其他语言要防

  • 02

    递归按 exp//2 折半，奇数轮补乘一次底数，别写成乘两次

  • 03

    x 为 0 且 n 为负的场景题目保证不出现，无需特判

复杂度

时间复杂度O(log n)
空间复杂度O(log n) 递归栈
