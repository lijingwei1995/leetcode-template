同构字符串

简单 LeetCode 原题 ↗
主模板哈希映射→

题目

给定两个字符串 s 和 t，判断它们是否同构。如果 s 中的字符可以被替换得到 t，那么这两个字符串是同构的：所有出现的字符都必须被替换，同时保留字符的顺序；两个字符不能映射到同一个字符上，但字符可以映射到自己。

示例 1
输入s = "egg", t = "add"
输出true
示例 2
输入s = "foo", t = "bar"
输出false

思路

字符要一一对应且不冲突，是哈希映射双向映射的信号：同时维护 s→t 与 t→s 两张表，逐对字符校验既有映射值是否一致。变化点在双向同时检查——单向映射会把 badc/baba 这类“两个字符映射到同一字符”误判为同构。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def isIsomorphic(self, s, t):3        s2t = {}4        t2s = {}5        for a, b in zip(s, t):6            if s2t.get(a, b) != b or t2s.get(b, a) != a:    # 变化点: 双向映射同时校验，防多对一7                return False8            s2t[a] = b9            t2s[b] = a10        return True

变化点代码

  • L6

    双向映射同时校验，防多对一

易错点

  • 01

    必须双向映射：只建 s→t 会漏掉 t 中两个字符映射到同一字符的情况

  • 02

    用 get(键, 本轮值) 的默认值技巧，映射缺失时视为可建立新映射

  • 03

    题目保证 len(s) == len(t)，zip 直接配对即可；通用写法可先比长度

复杂度

时间复杂度O(n)
空间复杂度O(n)（字符集大小）
