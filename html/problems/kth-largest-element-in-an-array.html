数组中的第K个最大元素

中等 LeetCode 原题 ↗
主模板堆与 TopK→

题目

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。注意是排序后的第 k 个最大元素，而不是第 k 个不同的元素。

示例 1
输入nums = [3,2,1,5,6,4], k = 2
输出5
示例 2
输入nums = [3,2,3,1,2,4,5,5,6], k = 4
输出4

思路

只求第 k 大不必整段排序：用容量为 k 的小顶堆保留“当前最大的 k 个”，堆顶即答案，这是堆 TopK 的信号。每个元素入堆，容量超过 k 就弹出堆顶最小值。变化点在于求最大反而用小顶堆，以及先压后弹保证堆始终非空。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1import heapq2 3class Solution:4    def findKthLargest(self, nums, k):5        h = []6        for x in nums:7            heapq.heappush(h, x)                # 变化点: 小顶堆，堆顶是当前第 k 大8            if len(h) > k:9                heapq.heappop(h)                # 变化点: 超容量弹出最小，保留最大 k 个10        return h[0]

变化点代码

  • L7

    小顶堆，堆顶是当前第 k 大

  • L9

    超容量弹出最小，保留最大 k 个

易错点

  • 01

    第 k 大用容量 k 的小顶堆，堆顶即答案；用大顶堆就得全部入堆再弹 k-1 次

  • 02

    先压后弹，保证堆从空到满的过程不会出错

  • 03

    重复元素也占名次，这是排序意义下的第 k 大

复杂度

时间复杂度O(n log k)
空间复杂度O(k)
