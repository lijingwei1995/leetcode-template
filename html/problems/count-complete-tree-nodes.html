完全二叉树的节点个数

中等 LeetCode 原题 ↗
主模板二叉树递归→相关模板二分查找→

题目

给定一棵完全二叉树的根节点 root，返回树的节点个数。完全二叉树中除最底层外每层都填满，最底层节点集中在左侧。进阶要求：遍历树节点数少于 O(n) 的时间复杂度。

示例 1
输入root = [1,2,3,4,5,6]
输出6
示例 2
输入root = []
输出0
示例 3
输入root = [1]
输出1

思路

完全二叉树“子树高度可直接量出”是关键信号：沿最左链量高度只要 O(h)。若左右等高，左子树是满树（2^h 个节点含根），答案为 2^h 加上递归右子树；否则右子树是满树，答案为 2^rh 加上递归左子树。变化点：每次递归至少砍掉一整棵满子树，结合树递归与二分思想，复杂度降到 O(log² n)。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def countNodes(self, root):3        if not root:4            return 05        lh = self._depth(root.left)6        rh = self._depth(root.right)7        if lh == rh:                              # 变化点: 左右等高 ⇒ 左子树满，整块砍掉8            return (1 << lh) + self.countNodes(root.right)9        return (1 << rh) + self.countNodes(root.left)   # 变化点: 右子树满，砍右保左10 11    def _depth(self, node):12        h = 013        while node:14            h += 115            node = node.left                      # 变化点: 沿最左链 O(h) 量高度16        return h

变化点代码

  • L7

    左右等高 ⇒ 左子树满，整块砍掉

  • L9

    右子树满，砍右保左

  • L15

    沿最左链 O(h) 量高度

易错点

  • 01

    满子树的节点数是 2^h（h 为其高度），指数层级别数错

  • 02

    等高时砍左子树递归右，不等高时砍右子树递归左，方向写反结果就错

  • 03

    空树返回 0，先判空再量高度，否则空指针

复杂度

时间复杂度O(log² n)
空间复杂度O(log n)
