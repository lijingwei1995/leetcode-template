二叉搜索树中第 K 小的元素

中等 LeetCode 原题 ↗
主模板BST 中序遍历→

题目

给定二叉搜索树的根节点 root 和整数 k，返回树中第 k 小的元素（k 从 1 开始计数）。进阶：如果树经常被插入、删除修改，能否进一步优化。

示例 1
输入root = [3,1,4,null,2], k = 1
输出1
示例 2
输入root = [5,3,6,2,4,null,null,1], k = 3
输出3

思路

第 k 小对应中序遍历的第 k 次访问，套 BST 中序模板：左递归、访问时计数、右递归。用全局计数器递减，减到 0 时锁定当前节点值并提前终止后续递归。变化点：访问计数代替收集全部序列，只需走 O(h + k) 个节点。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def kthSmallest(self, root, k):3        self.k = k4        self.ans = None5 6        def inorder(node):7            if not node or self.ans is not None:  # 变化点: 已找到答案立即剪枝8                return9            inorder(node.left)10            if self.ans is not None:11                return12            self.k -= 1                           # 变化点: 中序第 k 次访问即第 k 小13            if self.k == 0:14                self.ans = node.val15                return16            inorder(node.right)17 18        inorder(root)19        return self.ans

变化点代码

  • L7

    已找到答案立即剪枝

  • L12

    中序第 k 次访问即第 k 小

易错点

  • 01

    找到答案后要剪枝提前返回，不要把整棵树遍历完

  • 02

    k 从 1 开始，计数器减到 0 时才取值

  • 03

    剪枝条件用 ans is not None，不能用真值判断，0 也是合法答案

复杂度

时间复杂度O(h + k)
空间复杂度O(h)
