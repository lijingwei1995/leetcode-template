题目

假设你初始资本为 w，最多可以完成 k 个项目。第 i 个项目需要 capital[i] 的启动资本，完成后可获得 profits[i] 的纯利润（利润累加进资本）。每个项目只能选择一次，求最终可以获得的最大资本。

示例 1
输入k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
输出4
示例 2
输入k = 1, w = 0, profits = [1,2,3], capital = [0,1,2]
输出1

思路

资本只增不减，可启动项目的集合单调扩大：先按资本排序，用指针把资本达标的利润全部压入大顶堆，每轮取堆顶利润最高的项目完成。变化点在于“按资本排序 + 指针只前进 + 大顶堆取当前最优”的组合，堆空说明剩余项目都启动不了，提前退出。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1import heapq2 3class Solution:4    def findMaximizedCapital(self, k, w, profits, capital):5        projects = sorted(zip(capital, profits))6        heap = []                               # 当前可启动项目的利润大顶堆7        i, n = 0, len(projects)8        for _ in range(k):9            while i < n and projects[i][0] <= w:10                heapq.heappush(heap, -projects[i][1])   # 变化点: 资本达标的项目全部入堆11                i += 112            if not heap:13                break                           # 变化点: 无项目可做，提前结束14            w += -heapq.heappop(heap)           # 变化点: 每轮选利润最大的项目15        return w

变化点代码

  • L10

    资本达标的项目全部入堆

  • L13

    无项目可做，提前结束

  • L14

    每轮选利润最大的项目

易错点

  • 01

    每轮要把当前资本能启动的所有项目全部入堆，而不是只挑一个

  • 02

    资本只增不减，已入堆项目不会失效，指针单调前进避免重复扫描

  • 03

    堆空说明剩下的项目资本都不够，提前 break 防止空转 k 次

复杂度

时间复杂度O(n log n)（排序）+ O(k log n)
空间复杂度O(n)
