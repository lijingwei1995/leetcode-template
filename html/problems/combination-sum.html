组合总和

中等 LeetCode 原题 ↗
主模板回溯框架→

题目

给你一个无重复元素的整数数组 candidates 和一个目标整数 target，找出 candidates 中所有可以使数字之和等于 target 的不同组合。同一个数字可以被无限制重复选取，组合至少包含一个候选数字；按任意顺序返回答案。

示例 1
输入candidates = [2,3,6,7], target = 7
输出[[2,2,3],[7]]
示例 2
输入candidates = [2,3,5], target = 8
输出[[2,2,2,2],[2,3,3],[3,5]]

思路

“凑出 target 且可重复选取”是回溯框架的变体：递归参数带剩余额度 rest，每选一个 x 就 rest 减 x，rest 归零收集。变化点有两处——下一层仍从 i 开始（允许重复选当前数）；先把候选排序，遇到 x > rest 直接 break 剪枝，后面的候选只会更大。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def combinationSum(self, candidates, target):3        candidates.sort()                          # 变化点: 排序后才能用 break 剪枝4        res, path = [], []5 6        def backtrack(start, rest):7            if rest == 0:8                res.append(path[:])9                return10            for i in range(start, len(candidates)):11                x = candidates[i]12                if x > rest:13                    break                          # 变化点: 候选有序，后面只会更大14                path.append(x)15                backtrack(i, rest - x)             # 变化点: 可重复选取，下一层仍从 i 开始16                path.pop()17 18        backtrack(0, target)19        return res

变化点代码

  • L3

    排序后才能用 break 剪枝

  • L13

    候选有序，后面只会更大

  • L15

    可重复选取，下一层仍从 i 开始

易错点

  • 01

    下一层传 i 而不是 i + 1，否则重复选取失效直接漏解

  • 02

    剪枝用 break 不是 continue：排序后 x > rest，后续候选必然更大

  • 03

    rest == 0 收集、rest < 0 由剪枝兜底，不要在循环里再写冗余的 rest < 0 判断

复杂度

时间复杂度指数级（剪枝后为实际搜索树大小）
空间复杂度O(target / 最小候选值)（递归栈）
