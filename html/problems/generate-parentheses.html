括号生成

中等 LeetCode 原题 ↗
主模板回溯框架→

题目

给出数字 n，生成所有由 n 对括号组成、且每一个左括号都有对应右括号闭合的合法括号序列。可以按任意顺序返回答案。

示例 1
输入n = 3
输出["((()))","(()())","(())()","()(())","()()()"]
示例 2
输入n = 1
输出["()"]

思路

长度固定 2n、每步在 '(' 与 ')' 中二选一，信号是回溯框架，但选择受两条合法性约束：已用左括号数 < n 才能加 '('；已用右括号数 < 已用左括号数才能加 ')'。变化点在于用 left/right 计数代替扫描检查，长度凑满 2n 时 join 收集。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def generateParenthesis(self, n):3        res, path = [], []4 5        def backtrack(left, right):6            if len(path) == 2 * n:7                res.append(''.join(path))8                return9            if left < n:                           # 变化点: 左括号没用完就能加 '('10                path.append('(')11                backtrack(left + 1, right)12                path.pop()13            if right < left:                       # 变化点: 已用右括号少于左括号才合法14                path.append(')')15                backtrack(left, right + 1)16                path.pop()17 18        backtrack(0, 0)19        return res

变化点代码

  • L9

    左括号没用完就能加 '('

  • L13

    已用右括号少于左括号才合法

易错点

  • 01

    两条约束缺一不可，只判数量会生成 ')(' 这类非法前缀

  • 02

    加 ')' 的条件是 right < left（已用右括号少于已用左括号），写成 right < n 会提前产出非法串

  • 03

    长度凑满 2n 才收集，别用 left==n 就提前 join，此时右括号还没用完

复杂度

时间复杂度O(4^n / √n)（卡特兰数个合法序列）
空间复杂度O(n)（递归栈，不含输出）
