寻找峰值

题目

峰值元素是严格大于其左右相邻值的元素。给定数组 nums，其中 nums[i] != nums[i+1]，并约定边界外 nums[-1] = nums[n] = -∞。返回任意一个峰值元素的下标，要求时间复杂度为 O(log n)。

示例 1
输入nums = [1,2,3,1]
输出2
示例 2
输入nums = [1,2,1,3,5,6,4]
输出1 或 5

思路

数组虽不整体有序，但比较 nums[mid] 与右邻即可判断上坡还是下坡——每轮都能安全丢掉一半，属于边界二分信号。nums[mid] < nums[mid+1] 说明右侧必定存在峰值。变化点在于比较对象换成右邻元素而不是 target，区间收敛到 left == right 即峰值下标。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def findPeakElement(self, nums):3        left, right = 0, len(nums) - 14        while left < right:5            mid = (left + right) // 26            if nums[mid] < nums[mid + 1]:       # 变化点: 与右邻比较，上坡侧必有峰值7                left = mid + 18            else:9                right = mid10        return left

变化点代码

  • L6

    与右邻比较，上坡侧必有峰值

易错点

  • 01

    比较 nums[mid+1] 时 mid 最大只能取到 right-1，用 left < right 收敛保证不越界

  • 02

    峰值是局部定义（大于相邻），不是全局最大值

  • 03

    相邻元素互不相等是判断方向的隐含前提

复杂度

时间复杂度O(log n)
空间复杂度O(1)
