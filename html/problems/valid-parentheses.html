有效的括号

简单 LeetCode 原题 ↗
主模板栈与表达式→

题目

给定一个只包括 '('、')'、'{'、'}'、'['、']' 的字符串 s，判断字符串是否有效。有效字符串需满足：左括号必须用相同类型的右括号闭合；左括号必须以正确的顺序闭合；每个右括号都有一个对应的相同类型的左括号。

示例 1
输入s = "()[]{}"
输出true
示例 2
输入s = "([)]"
输出false

思路

括号匹配是栈与表达式的信号：遇左括号压栈，遇右括号弹出栈顶比对类型，嵌套顺序天然由栈保证。变化点在用字典建立右括号到左括号的对应，且栈空弹栈、扫描结束栈非空两种失败情形都要覆盖。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def isValid(self, s):3        pairs = {')': '(', ']': '[', '}': '{'}  # 变化点: 右括号到左括号的类型映射4        stack = []5        for ch in s:6            if ch in '([{':7                stack.append(ch)8            elif not stack or stack.pop() != pairs[ch]:     # 变化点: 栈空或类型不匹配都无效9                return False10        return not stack

变化点代码

  • L3

    右括号到左括号的类型映射

  • L8

    栈空或类型不匹配都无效

易错点

  • 01

    遇右括号时栈空要直接无效，先判空再弹栈

  • 02

    扫描结束后栈非空也是无效（左括号多余），不能只 return True

  • 03

    只统计左右括号个数相等不够，"([)]" 顺序错误会漏判

复杂度

时间复杂度O(n)
空间复杂度O(n)
