回文数

简单 LeetCode 原题 ↗

题目

给你一个整数 x，如果 x 是回文整数，返回 true；否则返回 false。回文整数是正着读和反着读都一样的整数，例如 121 是回文，而 123 不是。负数一律不是回文。

示例 1
输入x = 121
输出true
示例 2
输入x = -121
输出false

思路

负数与“非零的尾零数”必不是回文，先排除；再只反转一半数字与剩余前半比较，既不用字符串也不怕溢出，是按位模拟的变体。变化点在于循环条件 x > rev 控制只反转一半，比较时区分偶数位与奇数位（rev//10 丢弃中间位）。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def isPalindrome(self, x):3        if x < 0 or (x % 10 == 0 and x != 0):   # 变化点: 负数与尾零数直接排除4            return False5        rev = 06        while x > rev:                          # 变化点: 只反转一半7            rev = rev * 10 + x % 108            x //= 109        return x == rev or x == rev // 10       # 变化点: 奇数位丢弃中间位

变化点代码

  • L3

    负数与尾零数直接排除

  • L6

    只反转一半

  • L9

    奇数位丢弃中间位

易错点

  • 01

    10、100 这类尾零数不是回文，要先排除；0 本身是回文

  • 02

    比较要兼顾偶数位与奇数位：x == rev 或 x == rev // 10

  • 03

    不要反转整个数再比较，其他语言有溢出风险，也无谓多做一半功
