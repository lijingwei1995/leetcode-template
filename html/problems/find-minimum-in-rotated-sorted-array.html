寻找旋转排序数组中的最小值

中等 LeetCode 原题 ↗
主模板二分边界与旋转数组→

题目

已知一个长度为 n 的数组原本按升序排列，元素互不相同，并被旋转了 1 到 n 次。例如 [0,1,2,4,5,6,7] 可能变成 [4,5,6,7,0,1,2]。请找出并返回数组中的最小元素，要求时间复杂度为 O(log n)。

示例 1
输入nums = [3,4,5,1,2]
输出1
示例 2
输入nums = [11,13,15,17]
输出11

思路

旋转后数组由两段升序组成，最小值是第二段的起点，这是边界二分的信号。nums[mid] > nums[right] 说明最小值在右半；否则最小值在含 mid 的左半。变化点在于锚定右端点而不是左端点来判断方向，且 mid 可能就是答案，收缩时保留 right = mid。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def findMin(self, nums):3        left, right = 0, len(nums) - 14        while left < right:5            mid = (left + right) // 26            if nums[mid] > nums[right]:         # 变化点: 与右端点比较，最小值在右半7                left = mid + 18            else:9                right = mid                     # 变化点: mid 可能就是最小值，保留它10        return nums[left]

变化点代码

  • L6

    与右端点比较，最小值在右半

  • L9

    mid 可能就是最小值，保留它

易错点

  • 01

    锚定右端点而非左端点：与左端点比较无法区分“整体有序”和“最小值在右半”

  • 02

    mid 可能就是最小值，右收缩用 right = mid 而不是 mid - 1

  • 03

    用 left < right 收敛，区间只剩两个元素时也能正确停住

复杂度

时间复杂度O(log n)
空间复杂度O(1)
