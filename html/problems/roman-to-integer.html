罗马数字转整数

简单 LeetCode 原题 ↗
主模板哈希映射→

题目

罗马数字包含七种字符：I(1)、V(5)、X(10)、L(50)、C(100)、D(500)、M(1000)。通常小数字写在大数字右边表示相加，但存在六种减法形式：IV(4)、IX(9)、XL(40)、XC(90)、CD(400)、CM(900)。给定一个罗马数字字符串 s，将其转换成整数。

示例 1
输入s = "III"
输出3
示例 2
输入s = "MCMXCIV"
输出1994

思路

罗马数字规则可完全由“当前符号值与下一个符号值的大小关系”推出，哈希映射信号：建立字符到数值的表，扫描时若当前字符值小于下一个字符值就做减法，否则做加法。变化点在于比较对象是相邻两个字符，一次遍历即可完成转换。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def romanToInt(self, s):3        values = {"I": 1, "V": 5, "X": 10, "L": 50,4                  "C": 100, "D": 500, "M": 1000}5        total = 06        for i, ch in enumerate(s):7            if i + 1 < len(s) and values[ch] < values[s[i + 1]]:8                total -= values[ch]             # 变化点: 小值在大值左侧时做减法9            else:10                total += values[ch]11        return total

变化点代码

  • L8

    小值在大值左侧时做减法

易错点

  • 01

    判断依据是“当前值 < 下一个值”，只看相邻一个字符，不用回看更远

  • 02

    减法只发生在 IV/IX/XL/XC/CD/CM 六种组合，符合上述判据即天然覆盖

  • 03

    取 s[i+1] 前要判 i + 1 < len(s)，最后一个字符一定做加法

复杂度

时间复杂度O(n)
空间复杂度O(1)
