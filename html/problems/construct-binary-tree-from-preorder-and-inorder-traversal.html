从前序与中序遍历序列构造二叉树

中等 LeetCode 原题 ↗
主模板二叉树递归→相关模板分治→

题目

给定两个整数数组 preorder 和 inorder，其中 preorder 是二叉树的前序遍历，inorder 是同一棵树的中序遍历，构造二叉树并返回其根节点。假设树中没有重复的值。

示例 1
输入preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出[3,9,20,null,null,15,7]
示例 2
输入preorder = [-1], inorder = [-1]
输出[-1]

思路

前序首元素是根、中序中根的左边是左子树右边是右子树，信号是“分治构造”，套树递归模板：先建根，再按中序切出区间递归。变化点一：用哈希表把中序值映射到下标，避免每层线性扫描；变化点二：用一个自增指针顺序消耗前序数组，天然保证根的取用顺序与建树次序一致。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def buildTree(self, preorder, inorder):3        idx = {v: i for i, v in enumerate(inorder)}   # 变化点: 值→中序下标哈希，免线性扫描4        self.pos = 05 6        def build(left, right):7            if left > right:8                return None9            root = TreeNode(preorder[self.pos])10            self.pos += 1                             # 变化点: 前序指针顺序消耗根11            mid = idx[root.val]12            root.left = build(left, mid - 1)13            root.right = build(mid + 1, right)14            return root15 16        return build(0, len(inorder) - 1)

变化点代码

  • L3

    值→中序下标哈希，免线性扫描

  • L10

    前序指针顺序消耗根

易错点

  • 01

    先取前序元素建根、再查中序下标，self.pos 自增要放在建子树之前

  • 02

    递归边界是闭区间 [left, right]，left > right 返回 None

  • 03

    题目保证无重复值，哈希映射才成立；有重复时此法失效

复杂度

时间复杂度O(n)
空间复杂度O(n)（哈希表 + 递归栈）
