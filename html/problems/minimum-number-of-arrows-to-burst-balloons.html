用最少数量的箭引爆气球

中等 LeetCode 原题 ↗
主模板区间贪心→

题目

气球用水平方向上的区间表示：points[i] = [start_i, end_i]。一支箭沿 x 轴垂直射出，如果一支箭的坐标为 x，凡满足 start_i ≤ x ≤ end_i 的气球都会被引爆（端点相切也算命中）。射爆所有气球所需弓箭的最小数量是多少？

示例 1
输入points = [[10,16],[2,8],[1,6],[7,12]]
输出2（x=6 引爆前三个，x=12 引爆最后一个）
示例 2
输入points = [[1,2],[3,4],[5,6],[7,8]]
输出4

思路

最少箭数等价于最多不重叠区间数，是区间贪心的信号：按右端点排序，箭尽量射在当前最靠前的右端点上，能顺带引爆所有覆盖该点的气球。变化点在排序键是右端 x[1] 而非左端，且端点相切算命中、只有 start > prev_end 才补箭。

识别信号→ 套用模板→ 调整变化点

变化点代码

  • L3

    按右端点排序，箭尽量射在最早结束处

  • L7

易错点

  • 01

    排序键是右端点：让箭尽量射在最早结束的位置，才能覆盖最多后续气球

  • 02

    端点相切（start == prev_end）也算命中，判定新箭用 > 而不是 >=

  • 03

    坐标可能为负，prev_end 初值不能用 0，要用 None 或负无穷

复杂度

时间复杂度O(n log n)
空间复杂度O(1)（不计排序栈空间）
