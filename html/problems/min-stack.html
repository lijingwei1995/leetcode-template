最小栈

中等 LeetCode 原题 ↗
主模板数据结构设计→

题目

设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。实现 MinStack 类：push(val) 将元素压入栈；pop() 删除栈顶元素；top() 获取栈顶元素；getMin() 获取栈中最小元素。每个函数的时间复杂度都必须是 O(1)。

示例 1
输入操作序列：["MinStack","push","push","push","getMin","pop","top","getMin"]，参数 [[],[-2],[0],[-3],[],[],[],[]]
输出[null,null,null,null,-3,null,0,-2]
示例 2
输入操作序列：push(1)、push(1)、getMin()、pop()、getMin()
输出1、1、1

思路

要在 O(1) 内取最小值，是数据结构设计的信号：主栈正常进出，另设辅助栈同步保存“当前最小值”，辅助栈顶始终是全栈最小。变化点在 push 时 val <= 辅助栈顶才压入（相等也要压，否则重复最小值弹出后失配），pop 时弹出值等于辅助栈顶才同步弹出。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class MinStack:2    def __init__(self):3        self.stack = []4        self.min_stack = []                     # 变化点: 辅助栈同步保存当前最小值5 6    def push(self, val):7        self.stack.append(val)8        if not self.min_stack or val <= self.min_stack[-1]:     # 变化点: 相等也要压入9            self.min_stack.append(val)10 11    def pop(self):12        val = self.stack.pop()13        if val == self.min_stack[-1]:           # 变化点: 弹出的是当前最小则同步弹出14            self.min_stack.pop()15 16    def top(self):17        return self.stack[-1]18 19    def getMin(self):20        return self.min_stack[-1]

变化点代码

  • L4

    辅助栈同步保存当前最小值

  • L8

    相等也要压入

  • L13

    弹出的是当前最小则同步弹出

易错点

  • 01

    push 的判定必须是 <=：最小值重复出现时若不重复压入，pop 后辅助栈会空

  • 02

    pop 只在弹出值等于辅助栈顶时同步弹出，其余情况辅助栈不动

  • 03

    getMin 永远看辅助栈顶，不要遍历主栈找最小

复杂度

时间复杂度各操作 O(1)
空间复杂度O(n)
