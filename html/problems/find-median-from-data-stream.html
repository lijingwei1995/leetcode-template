数据流的中位数

困难 LeetCode 原题 ↗

题目

中位数是有序整数列表中的中间值；如果列表长度为偶数，中位数是两个中间值的平均。实现 MedianFinder 类：addNum(num) 从数据流中添加一个整数，findMedian() 返回目前所有元素的中位数。

示例 1
输入["MedianFinder","addNum","addNum","findMedian","addNum","findMedian"]\n[[],[1],[2],[],[3],[]]
输出[null,null,null,1.5,null,2.0]

思路

中位数要动态维护“较小一半”与“较大一半”的平衡：左半放大顶堆、右半放小顶堆，两堆大小差不超过 1，这是堆 TopK 的对顶堆变体。新数按与左堆顶的比较入堆，再把较大一侧的堆顶搬给另一侧保持平衡。变化点在于左堆用负数模拟大顶堆，以及奇数个元素时中位数就是左堆顶。

模板解法

Python 3
1import heapq2 3class MedianFinder:4    def __init__(self):5        self.left = []                          # 大顶堆（存负数），放较小一半6        self.right = []                         # 小顶堆，放较大一半7 8    def addNum(self, num):9        if not self.left or num <= -self.left[0]:10            heapq.heappush(self.left, -num)     # 变化点: 取负模拟大顶堆11        else:12            heapq.heappush(self.right, num)13        if len(self.left) > len(self.right) + 1:    # 变化点: 平衡两堆大小14            heapq.heappush(self.right, -heapq.heappop(self.left))15        elif len(self.left) < len(self.right):16            heapq.heappush(self.left, -heapq.heappop(self.right))17 18    def findMedian(self):19        if len(self.left) > len(self.right):20            return -self.left[0]21        return (-self.left[0] + self.right[0]) / 2

变化点代码

  • L10

    取负模拟大顶堆

  • L13

    平衡两堆大小

易错点

  • 01

    左堆存负数模拟大顶堆，取出堆顶要再取负还原

  • 02

    平衡目标是 len(left) == len(right) 或多 1，奇数个时中位数取左堆顶

  • 03

    两堆都为空时 findMedian 无定义，题目保证调用前至少有一次 addNum

复杂度

时间复杂度addNum O(log n)，findMedian O(1)
空间复杂度O(n)
