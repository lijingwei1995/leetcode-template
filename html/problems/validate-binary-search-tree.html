No.88 · 二叉搜索树

验证二叉搜索树

中等 LeetCode 原题 ↗
主模板BST 中序遍历→

题目

给定二叉树的根节点 root，判断它是否是一棵有效的二叉搜索树。有效 BST 定义：左子树所有节点值均小于根，右子树所有节点值均大于根，且左右子树本身也必须是有效 BST。注意不能只与直接孩子比较。

示例 1
输入root = [2,1,3]
输出true
示例 2
输入root = [5,1,4,null,null,3,6]
输出false

思路

BST 性质等价于“中序序列严格递增”，套 BST 中序模板做验证：递归左子树，失败则短路返回 False；用 prev 检查当前值是否大于上一个值；最后递归右子树。变化点：把中序访问改成逐个短路校验，任一步违规立即失败，无需真的收集整个序列。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def isValidBST(self, root):3        self.prev = None4 5        def inorder(node):6            if not node:7                return True8            if not inorder(node.left):9                return False10            if self.prev is not None and node.val <= self.prev:   # 变化点: 中序必须严格递增11                return False12            self.prev = node.val13            return inorder(node.right)14 15        return inorder(root)

变化点代码

  • L10

    中序必须严格递增

易错点

  • 01

    不能只比较父子两代，[5,4,6,null,null,3,7] 这类必须靠中序才能查出

  • 02

    严格递增要求 node.val > prev，相等也判无效

  • 03

    prev 用 is not None 判断，不能用真值判断，0 会误判

复杂度

时间复杂度O(n)
空间复杂度O(h)（最坏 O(n)）
