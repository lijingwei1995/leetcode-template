电话号码的字母组合

中等 LeetCode 原题 ↗
主模板回溯框架→

题目

给定一个仅包含数字 2-9 的字符串 digits，返回所有它能表示的字母组合。数字到字母的映射与电话键盘相同（如 '2' 对应 "abc"）。答案按任意顺序返回；digits 为空时返回空列表。

示例 1
输入digits = "23"
输出["ad","ae","af","bd","be","bf","cd","ce","cf"]
示例 2
输入digits = ""
输出[]

思路

每个数字位从映射字母串中选一个字符，选满所有位即得到一个组合，是回溯框架最标准的“按位做选择”：path 收集已选字符，下标 i 表示当前处理第几位。变化点在于选择列表来自映射表 phone[digits[i]]，终止条件是 i 走到 digits 末尾，收集时 join 成字符串快照。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def letterCombinations(self, digits):3        if not digits:4            return []5        phone = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl",6                 "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"}7        res, path = [], []8 9        def backtrack(i):10            if i == len(digits):                   # 变化点: 每个数字位都选完才收集11                res.append(''.join(path))12                return13            for ch in phone[digits[i]]:            # 变化点: 选择列表由数字映射给出14                path.append(ch)15                backtrack(i + 1)16                path.pop()17 18        backtrack(0)19        return res

变化点代码

  • L10

    每个数字位都选完才收集

  • L13

    选择列表由数字映射给出

易错点

  • 01

    digits 为空要特判返回 []，否则会返回 [''] 一个空串组合

  • 02

    收集时用 ''.join(path) 生成新串，直接 append(path) 会被后续 pop 改坏

  • 03

    映射表别漏写 7 的 'pqrs' 与 9 的 'wxyz'（4 个字母）

复杂度

时间复杂度O(4^n·n)（7、9 对应 4 个字母）
空间复杂度O(n)（递归栈，不含输出）
