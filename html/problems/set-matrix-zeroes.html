矩阵置零

中等 LeetCode 原题 ↗
主模板矩阵模拟→

题目

给定一个 m x n 的矩阵 matrix，如果一个元素为 0，则将其所在行和列的所有元素都设为 0。请使用原地算法，尽量减少额外空间的使用。

示例 1
输入matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出返回 null，matrix 变为 [[1,0,1],[0,0,0],[1,0,1]]
示例 2
输入matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出返回 null，matrix 变为 [[0,0,0,0],[0,4,5,0],[0,3,1,0]]

思路

置零且空间要求 O(1)，是矩阵模拟的原地标记信号：借用首行、首列充当标记数组，内部出现 0 就把对应行首与列首写成 0。变化点在三处——先记录首行首列自身是否本来就含 0，内部打标记，最后单独清理首行与首列。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def setZeroes(self, matrix):3        m, n = len(matrix), len(matrix[0])4        first_row = any(matrix[0][j] == 0 for j in range(n))5        first_col = any(matrix[i][0] == 0 for i in range(m))    # 变化点: 先记录首行首列自身是否含 06        for i in range(1, m):7            for j in range(1, n):8                if matrix[i][j] == 0:9                    matrix[i][0] = matrix[0][j] = 0             # 变化点: 内部 0 写入行首列首作标记10        for i in range(1, m):11            for j in range(1, n):12                if matrix[i][0] == 0 or matrix[0][j] == 0:13                    matrix[i][j] = 014        if first_row:15            for j in range(n):16                matrix[0][j] = 017        if first_col:                                           # 变化点: 最后单独清理首行首列18            for i in range(m):19                matrix[i][0] = 0

变化点代码

  • L5

    先记录首行首列自身是否含 0

  • L9

    内部 0 写入行首列首作标记

  • L17

    最后单独清理首行首列

易错点

  • 01

    首行首列是否本身含 0 必须在打标记之前用两个布尔记录，否则标记会把它们污染

  • 02

    打标记和按标记置零都只处理内部区域（1..m-1, 1..n-1），首行首列单独收尾

  • 03

    直接边扫边置零会让后续读到的 0 是污染值，必须先标记后统一置零

复杂度

时间复杂度O(mn)
空间复杂度O(1)
