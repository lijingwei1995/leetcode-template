单词接龙

困难 LeetCode 原题 ↗

题目

在字典 wordList 中找出从 beginWord 到 endWord 的最短转换序列的长度：每次转换只能改变一个字母，且中间单词都必须在字典中；beginWord 本身不计入序列长度。若不存在这样的转换序列，返回 0。序列的第一个单词是 beginWord，最后一个单词是 endWord。

示例 1
输入beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出5
示例 2
输入beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出0

思路

单词是节点，相差一个字母的单词之间连边，最短转换序列长度就是 BFS 的层数（按节点数计）。变化点在于邻居生成：对每个位置尝试替换 26 个字母，拼出新串查字典集合，命中且未访问才入队；endWord 不在字典时直接返回 0。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1from collections import deque2 3class Solution:4    def ladderLength(self, beginWord, endWord, wordList):5        words = set(wordList)6        if endWord not in words:                   # 变化点: 终点不在字典直接无解7            return 08        q = deque([(beginWord, 1)])                # 变化点: 步数按节点数计，起点为 19        seen = {beginWord}10        while q:11            word, step = q.popleft()12            if word == endWord:13                return step14            for i in range(len(word)):15                for ch in "abcdefghijklmnopqrstuvwxyz":16                    if ch == word[i]:17                        continue18                    nxt = word[:i] + ch + word[i + 1:]19                    if nxt in words and nxt not in seen:20                        seen.add(nxt)21                        q.append((nxt, step + 1))22        return 0

变化点代码

  • L6

    终点不在字典直接无解

  • L8

    步数按节点数计，起点为 1

易错点

  • 01

    endWord 不在 wordList 时直接返回 0，否则 BFS 会空跑

  • 02

    答案按节点数计（hit→hot→dot→dog→cog 为 5），起点占 1，别按边数返回 4

  • 03

    替换字母要拼成新串去查集合，在原串上原地改会污染当前状态

复杂度

时间复杂度O(N·26·L²)，N 为字典单词数、L 为单词长度
空间复杂度O(N·L)
