删除链表的倒数第 N 个结点

中等 LeetCode 原题 ↗
主模板链表哨兵与遍历→相关模板快慢指针→

题目

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。进阶：尝试使用一趟扫描实现。

示例 1
输入head = [1,2,3,4,5], n = 2
输出[1,2,3,5]
示例 2
输入head = [1], n = 1
输出[]

思路

删除倒数第 n 个节点是链表哨兵 + 快慢指针的信号：fast 先走 n 步拉开固定差距，再与 slow 同速前进，fast 到尾时 slow 恰停在目标前驱。变化点在 fast 起步于 dummy 走 n 步、删除用一行 slow.next = slow.next.next 完成。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def removeNthFromEnd(self, head, n):3        dummy = ListNode(0, head)4        fast = slow = dummy5        for _ in range(n):                      # 变化点: fast 先走 n 步拉开距离6            fast = fast.next7        while fast.next:8            fast = fast.next9            slow = slow.next10        slow.next = slow.next.next              # 变化点: slow 停在倒数第 n+1 个节点，跳过目标11        return dummy.next

变化点代码

  • L5

    fast 先走 n 步拉开距离

  • L10

    slow 停在倒数第 n+1 个节点，跳过目标

易错点

  • 01

    两个指针都要从 dummy 出发，否则删除头节点时没有前驱

  • 02

    fast 先走 n 步后循环条件是 fast.next 非空，保证 slow 停在目标前驱而不是目标

  • 03

    一趟扫描的关键是固定的 n 步差距，别先数总长度再走第二遍

复杂度

时间复杂度O(n)
空间复杂度O(1)
