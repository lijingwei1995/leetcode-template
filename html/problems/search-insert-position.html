搜索插入位置

简单 LeetCode 原题 ↗
主模板二分查找→

题目

给定一个按升序排列且无重复元素的整数数组 nums 和一个目标值 target，如果 target 在数组中就返回它的下标；否则返回它按顺序插入后数组仍保持有序的位置。要求算法时间复杂度为 O(log n)。

示例 1
输入nums = [1,3,5,6], target = 5
输出2
示例 2
输入nums = [1,3,5,6], target = 2
输出1

思路

数组有序，且“插入位置”恰好等于“第一个 >= target 的下标”，这是标准二分的信号。沿用左闭右开区间：nums[mid] < target 时答案必在右侧，否则 mid 可能就是答案。变化点在于相等时不立即返回、继续收缩，循环结束时 left 就是插入位置。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def searchInsert(self, nums, target):3        left, right = 0, len(nums)              # 变化点: 右开区间，插到末尾也能覆盖4        while left < right:5            mid = (left + right) // 26            if nums[mid] < target:              # 变化点: 找第一个 >= target 的位置7                left = mid + 18            else:9                right = mid10        return left

变化点代码

  • L3

    右开区间，插到末尾也能覆盖

  • L6

    找第一个 >= target 的位置

易错点

  • 01

    right 必须取 len(nums)，取 len(nums)-1 时插入到末尾的场景会漏

  • 02

    相等分支归入 right = mid，天然兼容 target 已存在的情况，不必单独处理

  • 03

    mid 必须向下取整，上取整会让 mid 越过右开边界导致越界

时间复杂度O(log n)
空间复杂度O(1)
