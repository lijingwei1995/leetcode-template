Z 字形变换

中等 LeetCode 原题 ↗

题目

将一个给定字符串 s 根据给定的行数 numRows，以从上往下、从左到右进行 Z 字形排列，之后再按行从左到右逐行读取，输出拼接成的字符串。例如 "PAYPALISHIRING" 按 3 行排列后输出 "PAHNAPLSIIGYIR"。

示例 1
输入s = "PAYPALISHIRING", numRows = 3
输出"PAHNAPLSIIGYIR"
示例 2
输入s = "PAYPALISHIRING", numRows = 4
输出"PINALSIGYAHRPI"

思路

字符要按 Z 形落到固定行上，字符串扫描信号：按行号顺序扫字符串，行号在 0 与 numRows-1 之间往返。变化点在于行号触到首行或末行时翻转方向，numRows == 1 时 rows 只有第 0 行必须特判返回原串。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def convert(self, s, numRows):3        if numRows == 1 or numRows >= len(s):   # 变化点: 单行时无需折叠，直接返回原串4            return s5        rows = [[] for _ in range(numRows)]6        row, going_down = 0, False7        for ch in s:8            rows[row].append(ch)9            if row == 0 or row == numRows - 1:  # 变化点: 触到首行或末行时掉头10                going_down = not going_down11            row += 1 if going_down else -112        return ''.join(''.join(r) for r in rows)

变化点代码

  • L3

    单行时无需折叠，直接返回原串

  • L9

    触到首行或末行时掉头

易错点

  • 01

    numRows == 1 必须特判，否则翻转会写到 rows[1] 导致下标越界

  • 02

    going_down 初值是 False，靠首行触发第一次翻转开始向下

  • 03

    numRows >= len(s) 时每行至多一个字符，直接返回原串即可

时间复杂度O(n)
空间复杂度O(n)
