路径总和

题目

给定二叉树的根节点 root 和表示目标和的整数 targetSum，判断是否存在从根节点到叶子节点的路径，使路径上所有节点值相加等于 targetSum。叶子节点是指没有子节点的节点。

示例 1
输入root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
输出true
示例 2
输入root = [1,2,3], targetSum = 5
输出false

思路

“根到叶路径 + 数值目标”是二叉树递归信号：把剩余目标和逐层下传做减法，到达叶子时判断剩余值是否恰为叶子值。变化点：只在叶子处判定，中间节点即使剩余减到 0 也必须继续，因为目标和必须以叶子结尾。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def hasPathSum(self, root, targetSum):3        if not root:4            return False5        if not root.left and not root.right:      # 变化点: 只在叶子处判定剩余目标6            return targetSum == root.val7        return self.hasPathSum(root.left, targetSum - root.val) or \8               self.hasPathSum(root.right, targetSum - root.val)

变化点代码

  • L5

    只在叶子处判定剩余目标

易错点

  • 01

    空树返回 False，即使 targetSum 为 0

  • 02

    必须走到叶子才能判定，中途剩余为 0 不算满足条件

  • 03

    递归下传用 targetSum - node.val 做减法，而不是累加后再比较

复杂度

时间复杂度O(n)
空间复杂度O(h)（最坏 O(n)）
