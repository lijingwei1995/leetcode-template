数字范围按位与

中等 LeetCode 原题 ↗
主模板位运算→

题目

给定整数区间 [left, right]，返回区间内所有数字按位与的结果（含 left 与 right 两个端点）。

示例 1
输入left = 5, right = 7
输出4
示例 2
输入left = 1, right = 2147483647
输出0

思路

区间内不同的低位一定会被夹在中间的数抹成 0，按位与的结果只剩二进制公共前缀。不断把 left 与 right 同时右移直到相等，再按移位次数左移还原。变化点在于用 shift 记录被消去的低位个数，还原时左移同样的位数。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def rangeBitwiseAnd(self, left, right):3        shift = 04        while left < right:                     # 变化点: 消去低位直到留下公共前缀5            left >>= 16            right >>= 17            shift += 18        return left << shift

变化点代码

  • L4

    消去低位直到留下公共前缀

易错点

  • 01

    left == right 时不进循环，直接返回该值，注意初值不要被改坏

  • 02

    区间最长可达 2^31，逐个按位与必然超时，只能走公共前缀

  • 03

    shift 要在右移时同步累加，还原时左移同样的位数

复杂度

时间复杂度O(log C)，C 为区间长度
空间复杂度O(1)
