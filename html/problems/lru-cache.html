LRU 缓存

中等 LeetCode 原题 ↗

题目

请你设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构。实现 LRUCache 类：LRUCache(capacity) 以正整数容量初始化；get(key) 如果密钥存在于缓存中则返回其值，否则返回 -1；put(key, value) 如果 key 已存在则变更其值，如果不存在则插入该组键值对，插入前若容量已满则逐出最久未使用的键。get 和 put 的每个函数时间复杂度必须为 O(1)。

示例 1
输入操作序列：["LRUCache","put","put","get","put","get","put","get","get","get"]，参数 [[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3],[4]]
输出[null,null,null,1,null,-1,null,-1,3,4]
示例 2
输入操作序列：LRUCache(1)、put(1,1)、get(1)、put(2,2)、get(2)
输出null、null、1、null、-1

思路

O(1) 的 get/put 且按访问时间淘汰，是数据结构设计的信号：哈希表负责 key 到节点的 O(1) 定位，双向链表维护使用新旧次序。变化点有三处——访问（get、put 旧键）后把节点摘下移到链表头部；容量满时淘汰尾部最久未用节点并同步删哈希表；哑头哑尾简化边界。

识别信号→ 套用模板→ 调整变化点

模板解法

1class Node:2    def __init__(self, key=0, value=0):3        self.key = key4        self.value = value5        self.prev = None6        self.next = None7 8 9class LRUCache:10    def __init__(self, capacity):11        self.cap = capacity12        self.map = {}                           # 变化点: 哈希表 key -> 链表节点，O(1) 定位13        self.head = Node()14        self.tail = Node()15        self.head.next = self.tail16        self.tail.prev = self.head              # 哑头尾间挂双向链表，头端最新、尾端最旧17 18    def _remove(self, node):19        node.prev.next = node.next20        node.next.prev = node.prev21 22    def _add_front(self, node):23        node.next = self.head.next24        node.prev = self.head25        self.head.next.prev = node26        self.head.next = node27 28    def get(self, key):29        if key not in self.map:30            return -131        node = self.map[key]32        self._remove(node)33        self._add_front(node)                   # 变化点: 访问后移到头部，表示最近使用34        return node.value35 36    def put(self, key, value):37        if key in self.map:38            node = self.map[key]39            node.value = value40            self._remove(node)41            self._add_front(node)42            return43        if len(self.map) >= self.cap:           # 变化点: 容量满时淘汰尾部最久未用节点44            last = self.tail.prev45            self._remove(last)46            del self.map[last.key]47        node = Node(key, value)48        self.map[key] = node49        self._add_front(node)

变化点代码

  • L12

    哈希表 key -> 链表节点，O(1) 定位

  • L33

    访问后移到头部，表示最近使用

  • L43

    容量满时淘汰尾部最久未用节点

易错点

  • 01

    put 已存在的键是“更新 + 移到头部”，不能当作新插入触发淘汰逻辑

  • 02

    淘汰的是哑尾前一个节点，摘链的同时必须 del 哈希表映射，否则泄漏

  • 03

    节点要存 key（淘汰时删映射用），只存 value 的话淘汰环节拿不到键

复杂度

时间复杂度get / put 均 O(1)
空间复杂度O(capacity)
