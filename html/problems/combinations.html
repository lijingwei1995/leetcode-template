组合

中等 LeetCode 原题 ↗

题目

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。可以按任意顺序返回答案。

示例 1
输入n = 4, k = 2
输出[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
示例 2
输入n = 1, k = 1
输出[[1]]

思路

组合与顺序无关，信号是回溯框架 + start 参数：每层从 start 开始枚举，下一层传 i+1，天然保证不重不漏且内部有序。变化点在于剪枝——path 已有 len 个，剩余 [x, n] 共 n-x+1 个数字，凑不满 k 就整层剪掉，把搜索树压到实际组合数规模。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def combine(self, n, k):3        res, path = [], []4 5        def backtrack(start):6            if len(path) == k:                     # 变化点: 凑满 k 个即收集7                res.append(path[:])8                return9            for x in range(start, n + 1):10                if len(path) + (n - x + 1) < k:    # 变化点: 剩余数字不够凑满，整层剪掉11                    return12                path.append(x)13                backtrack(x + 1)                   # 变化点: 组合传 i+1，顺序无关不重复14                path.pop()15 16        backtrack(1)17        return res

变化点代码

  • L6

    凑满 k 个即收集

  • L10

    剩余数字不够凑满，整层剪掉

  • L13

    组合传 i+1，顺序无关不重复

易错点

  • 01

    下一层传 x+1；传 x 会允许重复选取，不传推进会漏解

  • 02

    剪枝用 return 不是 continue：候选从 x 到 n 都不够，后面的只会更少

  • 03

    收集用 path[:] 拷贝快照，回溯复用同一个 path 列表

复杂度

时间复杂度O(C(n,k)·k)
空间复杂度O(k)（递归栈，不含输出）
