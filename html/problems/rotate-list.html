旋转链表

中等 LeetCode 原题 ↗

题目

给你一个链表的头节点 head，将链表每个节点向右移动 k 个位置后返回新的头节点。0 <= k <= 10^9，k 可能远大于链表长度。

示例 1
输入head = [1,2,3,4,5], k = 2
输出[4,5,1,2,3]
示例 2
输入head = [0,1,2], k = 4
输出[2,0,1]

思路

整链右移 k 位是链表哨兵的信号：先数出长度并把尾节点连到头成环，再从新尾断开。变化点在 k 对长度取模、新尾是倒数第 k+1 个节点（从头走 length-k-1 步），以及 k % length == 0 时先复原再返回。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def rotateRight(self, head, k):3        if not head or not head.next or k == 0:4            return head5        old = head6        length = 17        while old.next:8            old = old.next9            length += 110        old.next = head                         # 尾连头成环11        k %= length                             # 变化点: k 对长度取模12        if k == 0:13            old.next = None                     # 变化点: 无需旋转，先复原再返回14            return head15        cur = head16        for _ in range(length - k - 1):         # 新尾是倒数第 k+1 个节点17            cur = cur.next18        new_head = cur.next19        cur.next = None                         # 变化点: 从新尾断开环20        return new_head

变化点代码

  • L11

    k 对长度取模

  • L13

    无需旋转，先复原再返回

  • L19

    从新尾断开环

易错点

  • 01

    k 可能远大于长度，必须先 k %= length，否则循环越界或空转

  • 02

    成环后一定要断开：包括 k % length == 0 的提前返回分支也要恢复

  • 03

    新尾是倒数第 k+1 个节点，走 length - k - 1 步，别数错成 length - k

复杂度

时间复杂度O(n)
空间复杂度O(1)
