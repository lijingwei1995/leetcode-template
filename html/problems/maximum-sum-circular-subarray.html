环形子数组的最大和

中等 LeetCode 原题 ↗
主模板Kadane 算法→

题目

给定一个长度为 n 的环形整数数组 nums（首尾相接成环），返回其非空子数组的最大可能和。环形子数组允许跨过首尾边界，但不能使用同一位置两次，即子数组长度不超过 n。

示例 1
输入nums = [1,-2,3,-2]
输出3
示例 2
输入nums = [5,-3,5]
输出10

思路

环形答案只有两种来源：不跨界的普通最大子数组和，或跨界的“总和减去中间那段最小子数组和”。信号是 Kadane 模板跑两遍，最大、最小两套滚动变量在同一循环里同步推进。变化点在于全负数组的特判——此时最小子数组吞掉整个数组，total - best_min 会得到非法的 0（空段），必须直接返回 best_max。

识别信号→ 套用模板→ 调整变化点

模板解法

1class Solution:2    def maxSubarraySumCircular(self, nums):3        cur_max = best_max = float('-inf')4        cur_min = best_min = float('inf')5        total = 06        for x in nums:7            total += x8            cur_max = max(x, cur_max + x)9            best_max = max(best_max, cur_max)10            cur_min = min(x, cur_min + x)          # 变化点: 同步维护最小子数组和11            best_min = min(best_min, cur_min)12        if best_max < 0:                           # 变化点: 全负时直接返回最大元素13            return best_max14        return max(best_max, total - best_min)     # 变化点: 环形=max(不跨环, 总和-最小子数组)

变化点代码

  • L10

    同步维护最小子数组和

  • L12

    全负时直接返回最大元素

  • L14

    环形=max(不跨环, 总和-最小子数组)

易错点

  • 01

    全负数组必须返回 best_max，total - best_min 会算出 0 这个空段的假答案

  • 02

    跨界情形的本质是挖掉一段最小和，用等价转化而不是真的枚举起点

  • 03

    最大、最小两套滚动变量在同一循环里各自独立更新，别互相串值
