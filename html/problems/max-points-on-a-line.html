直线上最多的点数

困难 LeetCode 原题 ↗
主模板哈希映射→相关模板数学与按位模拟→

题目

给你一个点集 points，其中 points[i] = [xi, yi] 表示 X-Y 平面上的一个点。求同一条直线上最多有多少个点。本题保证所有给定的点互不相同。

示例 1
输入points = [[1,1],[2,2],[3,3]]
输出3
示例 2
输入points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]
输出4

思路

同一直线上的点相对同一锚点的方向向量成比例，浮点斜率有除零与精度双重风险，改用 gcd 约分后的最简整数对作哈希键。以每个点为锚点统计各方向的点数，取最大值加上锚点自身。变化点在于用最简整数方向对替代除法斜率，这正是数学模拟里的约分技巧。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1from collections import defaultdict2from math import gcd3 4class Solution:5    def maxPoints(self, points):6        n = len(points)7        if n <= 2:8            return n9        best = 010        for i in range(n):                      # 变化点: 以每个点为锚点统计方向11            x1, y1 = points[i]12            slopes = defaultdict(int)13            for j in range(n):14                if j == i:15                    continue16                dx, dy = points[j][0] - x1, points[j][1] - y117                g = gcd(dx, dy)                 # 变化点: gcd 约分成最简整数对作键18                slopes[(dx // g, dy // g)] += 119            best = max(best, max(slopes.values()) + 1)  # 变化点: 补上锚点自身20        return best

变化点代码

  • L10

    以每个点为锚点统计方向

  • L17

    gcd 约分成最简整数对作键

  • L19

    补上锚点自身

易错点

  • 01

    浮点斜率有除零（竖线）与精度双重风险，必须用整数方向对作键

  • 02

    gcd 约分要求两点不重合，本题保证点互异；若允许重合需单独计数

  • 03

    答案是某锚点下最大方向计数 + 1，最后别忘了补锚点自身

复杂度

时间复杂度O(n² log C)
空间复杂度O(n)
