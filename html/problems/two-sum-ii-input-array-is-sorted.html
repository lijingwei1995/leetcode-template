两数之和 II - 输入有序数组

题目

给你一个下标从 1 开始的整数数组 numbers，该数组已按非递减顺序排列。请找出满足相加之和等于 target 的两个数，并返回它们的数组下标（下标从 1 开始）。你可以假设每个输入只对应唯一的答案，且你不可以两次使用同一个元素。要求使用常数级的额外空间。

示例 1
输入numbers = [2,7,11,15], target = 9
输出[1,2]
示例 2
输入numbers = [2,3,4], target = 6
输出[1,3]

思路

数组有序且要找两数之和，对撞双指针信号：left、right 从两端起步，和太小移左端增大和，和太大移右端减小和。变化点在于返回下标要 +1 转成 1-based，且题目保证唯一解、命中即可返回。

1class Solution:2    def twoSum(self, numbers, target):3        left, right = 0, len(numbers) - 14        while left < right:5            s = numbers[left] + numbers[right]6            if s == target:7                return [left + 1, right + 1]    # 变化点: 题目下标从 1 开始，返回前加一8            if s < target:9                left += 1                       # 变化点: 和偏小移左端，和偏大移右端10            else:11                right -= 112        return []

变化点代码

  • L7

  • L9

    和偏小移左端，和偏大移右端

易错点

  • 01

    返回值要 +1 转成 1-based，直接返回 left、right 是最高频错误

  • 02

    移动规则不能写反：和太小只能靠 left 右移增大，和太大靠 right 左移减小

  • 03

    题目保证唯一解，命中即返回，无需继续扫描或去重
