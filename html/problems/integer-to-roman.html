整数转罗马数字

中等 LeetCode 原题 ↗
主模板数学与按位模拟→

题目

给定一个整数 num，将其转换为对应的罗马数字表示，输入范围 1 <= num <= 3999。罗马数字由 I、V、X、L、C、D、M 七种符号及六种减法形式 IV、IX、XL、XC、CD、CM 组成。

示例 1
输入num = 3749
输出"MMMDCCXLIX"
示例 2
输入num = 58
输出"LVIII"

思路

把罗马数字的 13 种符号（含 900/400/90/40/9/4 六种减法形式）从大到小排成对照表，模拟信号：每轮尽量多用最大的符号并扣减 num，直到归零。变化点在于减法形式作为独立表项参与贪心匹配，且同一符号可能连续使用（如 MMM）要用 while。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def intToRoman(self, num):3        table = [(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),4                 (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),5                 (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")]6        result = []7        for value, symbol in table:             # 变化点: 13 项符号表按数值降序贪心匹配8            while num >= value:9                result.append(symbol)10                num -= value11        return "".join(result)

变化点代码

  • L7

    13 项符号表按数值降序贪心匹配

易错点

  • 01

    对照表必须按数值降序，且不能漏掉 CM/XC/IX 等减法形式，否则会出现 IIII 这类非法连写

  • 02

    同一符号可能连续使用，内层要用 while 而不是 if

  • 03

    num 范围限定 1 到 3999，超出范围无合法表示，不必处理

复杂度

时间复杂度O(1)（符号表固定 13 项）
空间复杂度O(1)
