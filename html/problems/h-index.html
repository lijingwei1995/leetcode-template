题目

给你一个整数数组 citations，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数。计算并返回该研究者的 h 指数：h 代表“高引用次数”，即至少有 h 篇论文分别被引用了至少 h 次。

示例 1
输入citations = [3,0,6,1,5]
输出3
示例 2
输入citations = [1,3,1]
输出1

思路

h 不可能超过论文总数 n，计数信号：把引用次数截断到 n，用长度 n+1 的桶统计每档引用的篇数。从高到低累加“引用至少 h 次的篇数”，首次满足 total >= h 的 h 就是答案。变化点在于超过 n 的引用统一并入最高桶，以及倒序累加时的判定条件是 total >= h。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def hIndex(self, citations):3        n = len(citations)4        buckets = [0] * (n + 1)5        for c in citations:6            buckets[min(c, n)] += 1             # 变化点: 引用超过 n 的并入最高桶7        total = 08        for h in range(n, 0, -1):               # 变化点: 从高到低累加“引用至少 h 次”的篇数9            total += buckets[h]10            if total >= h:11                return h12        return 0

变化点代码

  • L6

    引用超过 n 的并入最高桶

  • L8

    从高到低累加“引用至少 h 次”的篇数

易错点

  • 01

    引用次数要先 min(c, n) 截断，否则桶下标越界

  • 02

    判定条件是 total >= h（篇数不少于引用数），写反方向会返回偏大的 h

  • 03

    也可以排序后从大到小扫描，但计数桶法无需排序，时间 O(n)

复杂度

时间复杂度O(n)
空间复杂度O(n)
