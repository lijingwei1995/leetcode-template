二叉树的锯齿形层序遍历

中等 LeetCode 原题 ↗
主模板层序遍历（BFS）→

题目

给定二叉树的根节点 root，返回其节点值的锯齿形层序遍历：第一层从左往右，第二层从右往左，如此逐层交替，结果按层分组为二维数组。

示例 1
输入root = [3,9,20,null,null,15,7]
输出[[3],[20,9],[15,7]]
示例 2
输入root = [1]
输出[[1]]

思路

层序模板加层奇偶标记：仍然整层快照收集节点值，偶数层保持原序、奇数层反转后写入答案。变化点：只在输出阶段对 vals 做反转，队列内孩子仍按左→右顺序收集，下一层的遍历顺序不受影响。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def zigzagLevelOrder(self, root):3        if not root:4            return []5        res = []6        queue = [root]7        level = 08        while queue:9            vals = [node.val for node in queue]10            res.append(vals[::-1] if level % 2 else vals)   # 变化点: 奇数层反转输出11            queue = [c for node in queue for c in (node.left, node.right) if c]12            level += 113        return res

变化点代码

  • L10

    奇数层反转输出

易错点

  • 01

    反转只作用于输出列表，不要反转队列本身，否则下一层孩子顺序错乱

  • 02

    层号从 0 开始，第 0 层（根层）是正序

  • 03

    空树返回 []

复杂度

时间复杂度O(n)
空间复杂度O(n)（队列）
