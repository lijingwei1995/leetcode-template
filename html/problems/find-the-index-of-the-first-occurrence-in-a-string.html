找出字符串中第一个匹配项的下标

简单 LeetCode 原题 ↗
主模板字符串扫描与模拟→

题目

给你两个字符串 haystack 和 needle，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回 -1。本题约定 needle 为空字符串时返回 0。

示例 1
输入haystack = "sadbutsad", needle = "sad"
输出0
示例 2
输入haystack = "leetcode", needle = "leeto"
输出-1

思路

在主串中找模式串首现位置，字符串扫描信号：从每个可行起点 i 出发，内层循环逐字符比对 needle，比对走满 m 个字符即命中。变化点在于外层起点只需扫到 n-m，且失配立即换下一个起点（进阶可换 KMP 把均摊降到 O(n+m)）。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def strStr(self, haystack, needle):3        n, m = len(haystack), len(needle)4        for i in range(n - m + 1):              # 变化点: 起点最多到 n-m，防止越界5            j = 06            while j < m and haystack[i + j] == needle[j]:7                j += 18            if j == m:                          # 变化点: 内层走满 m 个字符即完整匹配9                return i10        return -1

变化点代码

  • L4

    起点最多到 n-m，防止越界

  • L8

    内层走满 m 个字符即完整匹配

易错点

  • 01

    外层范围是 range(n - m + 1)，写成 n - m 会漏掉末尾起点

  • 02

    needle 比 haystack 长时 range 为空，直接返回 -1，无需特判

  • 03

    KMP 是进阶写法，暴力扫描在题目数据范围内即可通过

复杂度

时间复杂度O(n·m)
空间复杂度O(1)
