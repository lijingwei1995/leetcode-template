随机链表的复制

中等 LeetCode 原题 ↗
主模板哈希映射→相关模板链表哨兵与遍历→

题目

给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random，该指针可以指向链表中的任何节点或空节点。构造这个链表的深拷贝，返回复制链表的头节点；复制链表中的节点不应引用原链表中的任何节点（用 next 和 random 指向的节点在原链表和复制链表中应一一对应）。

示例 1
输入head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出[[7,null],[13,0],[11,4],[10,2],[1,0]]
示例 2
输入head = []
输出[]

思路

带 random 指针的深拷贝是哈希映射的信号：用旧节点到新节点的字典查表复制，next 与 random 都从表里取。变化点在两遍扫描——先建全部新节点再逐个接指针，random 为 None 时 get 恰好返回 None。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def copyRandomList(self, head):3        if not head:4            return None5        old_new = {}                            # 变化点: 旧节点 -> 新节点的映射6        cur = head7        while cur:8            old_new[cur] = Node(cur.val)9            cur = cur.next10        cur = head11        while cur:12            old_new[cur].next = old_new.get(cur.next)13            old_new[cur].random = old_new.get(cur.random)   # 变化点: random 也查表复制14            cur = cur.next15        return old_new[head]

变化点代码

  • L5

    旧节点 -> 新节点的映射

  • L13

    random 也查表复制

易错点

  • 01

    必须两遍：先建完全部新节点，否则 random 指向的目标可能还没建出来

  • 02

    next 与 random 都用 dict.get 取，源为 None 时 get 返回 None 恰好正确

  • 03

    字典的 key 是旧节点对象本身，不是节点值（值可能重复）

复杂度

时间复杂度O(n)
空间复杂度O(n)
