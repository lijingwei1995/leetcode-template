题目

给定一个 n × n 的二维矩阵 matrix 表示一幅图像，请你将图像顺时针旋转 90 度。必须在原地旋转图像，即直接修改输入的二维矩阵，不要使用另一个矩阵来旋转图像。

示例 1
输入matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出返回 null，matrix 变为 [[7,4,1],[8,5,2],[9,6,3]]
示例 2
输入matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出返回 null，matrix 变为 [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

思路

原地旋转 90° 是矩阵模拟的坐标变换信号：顺时针旋转 90° 等价于先沿主对角线转置、再把每一行左右翻转，两步都能原地完成。变化点在转置只遍历上三角（j 从 i+1 开始），全矩阵交换会互相抵消。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def rotate(self, matrix):3        n = len(matrix)4        for i in range(n):5            for j in range(i + 1, n):6                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]     # 变化点: 沿主对角线转置，只走上三角7        for row in matrix:8            row.reverse()                           # 变化点: 再逐行左右翻转，得到顺时针 90°

变化点代码

  • L6

    沿主对角线转置，只走上三角

  • L8

    再逐行左右翻转，得到顺时针 90°

易错点

  • 01

    转置只能遍历上三角，j 从 0 开始会让每个元素被交换两次、矩阵回到原样

  • 02

    顺序必须是先转置后左右翻转；先翻转再转置得到的是逆时针旋转

  • 03

    题目要求原地操作，不能用新建矩阵接住结果再赋值回去

复杂度

时间复杂度O(n²)
空间复杂度O(1)
