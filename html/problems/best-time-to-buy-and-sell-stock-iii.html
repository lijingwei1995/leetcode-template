买卖股票的最佳时机 III

题目

给定一个数组 prices，它的第 i 个元素是一支给定股票第 i 天的价格。你最多可以完成两笔交易（买一次卖一次算一笔），但不能同时持有多笔股票。求能获得的最大利润。

示例 1
输入prices = [3,3,5,0,0,3,1,4]
输出6
示例 2
输入prices = [1,2,3,4,5]
输出4

思路

每天只关心“第几次买入 / 卖出后”的收益，是股票状态机 DP。用 buy1、sell1、buy2、sell2 四个状态滚动：第二次买入要使用第一次卖出后的利润。变化点在于交易次数的顺序不能颠倒。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def maxProfit(self, prices):3        buy1 = buy2 = -float('inf')4        sell1 = sell2 = 05        for p in prices:6            buy1 = max(buy1, -p)                 # 变化点: 第一次买入7            sell1 = max(sell1, buy1 + p)         # 变化点: 第一次卖出8            buy2 = max(buy2, sell1 - p)          # 变化点: 第二次买入使用第一次利润9            sell2 = max(sell2, buy2 + p)10        return sell2

  • L7

易错点

  • 01

    buy 状态初始化为负无穷，sell 初始化为 0

  • 02

    更新顺序必须是 buy1 → sell1 → buy2 → sell2

  • 03

    最多两笔交易，可以少于两笔，sell2 天然包含这种情况
