填充每个节点的下一个右侧节点指针 II

中等 LeetCode 原题 ↗
主模板层序遍历（BFS）→

题目

给定二叉树的根节点 root，填充它的每个 next 指针，让该指针指向其下一个右侧节点。如果找不到下一个右侧节点，则将 next 指针置为 null。初始状态下所有 next 指针都是 null，且树不一定是完美二叉树。

示例 1
输入root = [1,2,3,4,5,null,7]
输出[1,#,2,3,#,4,5,7,#]

思路

“逐层连接”直接指向层序模板：队列快照就是同一层，处理第 i 个节点时让同层前一个的 next 指向它即可，整层串成一条链。孩子判空后收进新队列进入下一层。变化点：利用枚举下标在同层内串链，无需 dummy 节点或指针跳跃技巧。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def connect(self, root):3        if not root:4            return None5        queue = [root]6        while queue:7            nxt = []8            for i, node in enumerate(queue):9                if i:                                 # 变化点: 同层前一个节点的 next 指向当前节点10                    queue[i - 1].next = node11                if node.left:12                    nxt.append(node.left)13                if node.right:14                    nxt.append(node.right)15            queue = nxt16        return root

变化点代码

  • L9

    同层前一个节点的 next 指向当前节点

易错点

  • 01

    树不是满二叉树，孩子入队前必须判空

  • 02

    i == 0 的节点没有前驱，要跳过串链，否则会接到上一层末尾

  • 03

    每层处理完用新列表替换队列，跨层节点不能混在同一个快照里

复杂度

时间复杂度O(n)
空间复杂度O(n)（队列）
