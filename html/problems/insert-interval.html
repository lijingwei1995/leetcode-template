插入区间

中等 LeetCode 原题 ↗
主模板区间贪心→

题目

给你一个无重叠的、按照区间起始端点排序的区间列表 intervals，其中 intervals[i] = [start_i, end_i]。再给你一个新区间 newInterval，你需要将 newInterval 插入列表中，使得列表中的所有区间仍然按起始端点排序且互不重叠。必要时可以合并相邻甚至重叠的区间，直接返回插入后的区间列表即可。

示例 1
输入intervals = [[1,3],[6,9]], newInterval = [2,5]
输出[[1,5],[6,9]]
示例 2
输入intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
输出[[1,2],[3,10],[12,16]]

思路

往有序无重叠区间中插入新区间，是区间贪心的三段式信号：先把起点之前完全不重叠的区间放入结果，再逐个合并与新区间重叠的部分，最后接回剩余区间。变化点在合并循环的条件 intervals[i][0] <= newInterval[1]（相接也算重叠），以及 newInterval 的就地扩张。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1class Solution:2    def insert(self, intervals, newInterval):3        res = []4        i, n = 0, len(intervals)5        while i < n and intervals[i][1] < newInterval[0]:   # 变化点: 左侧完全不重叠的直接放入6            res.append(intervals[i])7            i += 18        while i < n and intervals[i][0] <= newInterval[1]:  # 变化点: 与新区间重叠的逐个合并9            newInterval[0] = min(newInterval[0], intervals[i][0])10            newInterval[1] = max(newInterval[1], intervals[i][1])11            i += 112        res.append(newInterval)13        while i < n:                                        # 变化点: 右侧剩余接回14            res.append(intervals[i])15            i += 116        return res

变化点代码

  • L5

    左侧完全不重叠的直接放入

  • L8

    与新区间重叠的逐个合并

  • L13

    右侧剩余接回

易错点

  • 01

    三段缺一不可：只合并不接尾部会把右侧区间弄丢

  • 02

    左侧过滤用 intervals[i][1] < 新区间起点，合并判定用 intervals[i][0] <= 新区间终点

  • 03

    合并过程中 newInterval 就地扩张即可，不需要复制每个旧区间

复杂度

时间复杂度O(n)
空间复杂度O(n)
