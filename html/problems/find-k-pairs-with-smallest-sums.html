查找和最小的 K 对数字

中等 LeetCode 原题 ↗
主模板堆与 TopK→

题目

给定两个以升序排列的整数数组 nums1 和 nums2，以及一个整数 k，返回和最小的 k 个数对 (u, v)，其中 u 来自 nums1，v 来自 nums2。数对顺序按和从小到大排列。

示例 1
输入nums1 = [1,7,11], nums2 = [2,4,6], k = 3
输出[[1,2],[1,4],[1,6]]
示例 2
输入nums1 = [1,1,2], nums2 = [1,2,3], k = 2
输出[[1,1],[1,1]]

思路

数对 (i, j) 的最小后继是 (i, j+1)：把每行（固定 i）的首数对放入小顶堆，弹出谁就推进谁的同行下一列，类似多路归并。变化点在于堆元素存 (和, i, j) 三元组，且 i 只需初始化前 k 行，更靠后的数对不可能进入前 k 小。

识别信号→ 套用模板→ 调整变化点

模板解法

Python 3
1import heapq2 3class Solution:4    def kSmallestPairs(self, nums1, nums2, k):5        heap = []6        for i in range(min(k, len(nums1))):     # 变化点: 只取前 k 行的首数对建堆7            heapq.heappush(heap, (nums1[i] + nums2[0], i, 0))8        res = []9        while heap and len(res) < k:10            s, i, j = heapq.heappop(heap)11            res.append([nums1[i], nums2[j]])12            if j + 1 < len(nums2):              # 变化点: 弹出后推进同行的 j13                heapq.heappush(heap, (nums1[i] + nums2[j + 1], i, j + 1))14        return res

变化点代码

  • L6

    只取前 k 行的首数对建堆

  • L12

    弹出后推进同行的 j

易错点

  • 01

    堆中存 (和, i, j)，弹出后只推进 j + 1，i 方向的覆盖靠初始建堆

  • 02

    i 只初始化到 min(k, len(nums1))，后面行的首数对不可能进前 k 小

  • 03

    数对按位置计数，相同值不同下标的数对（如 [1,1] 与 [1,1]）都要保留

复杂度

时间复杂度O(k log k)
空间复杂度O(k)
