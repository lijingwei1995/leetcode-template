字符串 DP

两个前缀之间的最优解，比较末尾字符。

3 道题 O(mn) 时间，O(mn) 或 O(n) 空间

核心思路

dp[i][j] 表示 s 的前 i 个字符与 t 的前 j 个字符的关系（编辑距离、是否交错、是否匹配）。比较 s[i-1] 与 t[j-1] 决定转移；回文类用区间 dp[i][j]。

!

本模板在题库中关联 3 道题，其中 3 道以它为主模板。先判断题型，再动手写代码。

模板骨架

Python 3
1dp = [[0] * (n + 1) for _ in range(m + 1)]2for i in range(m + 1):3    dp[i][0] = i          # 变化点：边界初始化4for j in range(n + 1):5    dp[0][j] = j6for i in range(1, m + 1):7    for j in range(1, n + 1):8        if s[i-1] == t[j-1]:9            dp[i][j] = dp[i-1][j-1]10        else:11            dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1   # 变化点：编辑操作12return dp[m][n]

高亮行是应用时需要替换或调整的地方，下面逐条说明。

变化点

  • 编辑距离：增、删、替换三种操作取 min + 1

  • 交错字符串：dp 为 bool，按当前字符选择来源

  • 最长回文子串：区间 dp，或中心扩展

  • LCS：匹配则左上 + 1，否则取 max
