层序遍历（BFS）

一层一批，用队列推进。

6 道题 O(n) 时间，O(n) 空间

核心思路

队列保存当前层节点，for len(q) 锁定这一层；层内可以取最后一个（右视图）、求平均、按奇偶反转，或把 next 指针串起来。

!

本模板在题库中关联 6 道题，其中 5 道以它为主模板。先判断题型，再动手写代码。

识别信号

看到下面这些特征，优先想到这个模板；如果同时符合多个模板，再看哪一条约束最紧。

  1. 01按层输出 / 右视图 / 层平均
  2. 02锯齿形遍历
  3. 03填充 next 指针

模板骨架

1q = deque([root])2while q:3    for _ in range(len(q)):    # 一层一批4        node = q.popleft()5        ...6        if node.left: q.append(node.left)     # 变化点：入队与层内处理7        if node.right: q.append(node.right)

高亮行是应用时需要替换或调整的地方，下面逐条说明。

变化点

  • 右视图：记录每层最后一个节点

  • 层平均：层内求和后除以当前层大小

  • 锯齿：按层号决定是否反转

  • next 指针：层内记录 prev，prev.next = node
