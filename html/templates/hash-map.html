哈希映射

用空间换时间，把“找配对”变成 O(1)。

3 道题 O(n) 时间，O(n) 空间

核心思路

遍历时把已经见过的信息存入哈希表，查询当前元素需要的配对。先想清楚 key 与 value 的语义：值→下标、字符→字符、规范形→分组。

!

本模板在题库中关联 3 道题，其中 2 道以它为主模板。先判断题型，再动手写代码。

识别信号

看到下面这些特征，优先想到这个模板；如果同时符合多个模板，再看哪一条约束最紧。

  1. 01两数之和、重复元素
  2. 02字符双射（同构、单词规律）
  3. 03异位词分组、连续序列

变化点

  • 值 → 下标：两数之和

  • 字符双向映射：同构字符串、单词规律

  • 排序后的字符串作 key：字母异位词分组

  • 集合 + 只从连续段起点扩展：最长连续序列
