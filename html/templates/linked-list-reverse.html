链表反转

三个指针原地掉头，区间反转再接回。

0 道题 O(n) 时间，O(1) 空间

核心思路

prev / cur / nxt 三指针逐个反转 next。区间反转先走到 left 前一个节点，记住连接点，反转指定数量后把三段接回。

模板骨架

Python 3
1prev, cur = None, head2while cur:3    nxt = cur.next4    cur.next = prev            # 变化点：反转区间边界5    prev, cur = cur, nxt6return prev

高亮行是应用时需要替换或调整的地方，下面逐条说明。

变化点

  • 反转 [left, right]：记录 left 前驱与反转段头尾

  • K 个一组：先数够 k 个，再反转这一段并接回

  • 递归写法：先反转后面的部分，再处理当前节点
