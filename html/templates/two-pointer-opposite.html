对撞双指针

左右夹逼，每一步排除一个不可能的候选。

7 道题 O(n) 时间，O(1) 空间

核心思路

left 与 right 从两端向中间收缩。每次根据当前状态决定移动哪一侧，并证明被排除的一侧不可能产生更优解。

!

本模板在题库中关联 7 道题，其中 7 道以它为主模板。先判断题型，再动手写代码。

识别信号

看到下面这些特征，优先想到这个模板；如果同时符合多个模板，再看哪一条约束最紧。

  1. 01有序数组求两数之和 / 三数之和
  2. 02两端向中间的最优值问题（面积、雨水）
  3. 03回文判断或从后往前合并

模板骨架

Python 3
1left, right = 0, len(nums) - 12while left < right:3    if 满足条件:                 # 变化点：移动哪一侧4        left += 15    else:6        right -= 1

高亮行是应用时需要替换或调整的地方，下面逐条说明。

变化点

  • 移动规则不同：和太小移 left，容器高度矮的一侧内移

  • 从后往前合并两个有序数组，避免覆盖未处理元素

  • 固定一个数后，在剩余区间做对撞双指针（三数之和）
