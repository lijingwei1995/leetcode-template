网格 DFS / FloodFill

把网格当图，访问后立即标记。

0 道题 O(mn) 时间，O(mn) 递归栈

核心思路

每个格子向四邻接扩展；进入时检查边界与条件，随后标记已访问，避免重复和死循环。需要枚举路径时改成回溯并撤销标记。

!

本模板在题库中关联 0 道题，其中 0 道以它为主模板。先判断题型，再动手写代码。

看到下面这些特征，优先想到这个模板；如果同时符合多个模板，再看哪一条约束最紧。

  2. 02连通块染色

变化点

  • 岛屿数量：每个未访问陆地启动一次 DFS 并计数

  • 被围绕区域：从四条边界的 O 反向标记，剩下的是被围的
