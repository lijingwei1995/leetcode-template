拓扑排序

入度为 0 的先出队，能输出全部节点则无环。

0 道题 O(V+E) 时间，O(V+E) 空间

核心思路

根据依赖关系建有向图并统计入度，把入度为 0 的节点入队；逐个出队、删除其出边并更新入度。若最终输出数量等于节点数，则无环。
