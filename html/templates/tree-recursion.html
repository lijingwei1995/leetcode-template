二叉树递归

先定义 dfs 返回值的语义，再决定前序还是后序处理。

13 道题 O(n) 时间，O(h) 递归栈

核心思路

二叉树问题几乎都能落到“递归左右子树”上。明确 dfs 返回什么（高度、和、是否存在、路径），需要跨子树信息时用全局变量或返回多个值。

!

本模板在题库中关联 13 道题，其中 12 道以它为主模板。先判断题型，再动手写代码。

识别信号

看到下面这些特征，优先想到这个模板；如果同时符合多个模板，再看哪一条约束最紧。

  1. 01求深度、节点数、路径
  2. 02判断相同 / 对称 / 平衡
  3. 03构造树、最近公共祖先、最大路径和

模板骨架

Python 3
1def dfs(node):2    if not node:3        return 0                # 变化点：空节点返回值4    left = dfs(node.left)5    right = dfs(node.right)6    return 1 + max(left, right) # 变化点：后序汇合逻辑

高亮行是应用时需要替换或调整的地方，下面逐条说明。

变化点

  • 求深度 / 节点数：返回单值累加

  • 路径和：向下传递剩余 target 或当前数字

  • 构造树：用下标哈希定位根，递归区间

  • 最大路径和：返回单边最大值，全局记录左右拐点

  • LCA：左右都找到则当前节点为答案

  • 原地展开：先保存 right，再改指针
