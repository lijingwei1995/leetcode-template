字典树

公共前缀共享一条路径。

0 道题 O(L) 每次操作，O(总字符数) 空间

核心思路

每个节点代表一个字符，根到节点构成前缀；插入沿字符逐层建节点，末尾打标记。查询前缀只需沿路径走，通配符则 DFS 枚举分支。

模板骨架

Python 3
1class Trie:2    def __init__(self):3        self.root = {}4        self.end = '#'5    def insert(self, word):6        node = self.root7        for ch in word:8            node = node.setdefault(ch, {})   # 变化点：节点结构9        node[self.end] = True

高亮行是应用时需要替换或调整的地方，下面逐条说明。

变化点

  • 前缀查询：走完路径即存在前缀

  • 通配符 .：DFS 枚举所有子节点

  • 单词搜索 II：Trie + 网格回溯，节点保存完整单词

  • 也可用 26 叉数组实现，查询更快但更占空间
